# App Store 素材

基于指定版本的真实应用界面与功能证据，交付可检查、可复用的本地素材及清单。

## 1. 固定素材任务

输入：用户请求或送审任务交接、应用源码/归档/截图、平台、目标版本、已有素材和输出边界。
确认应用名称、bundleId、iOS/macOS、实际设备族、所需素材范围及版本依据；appId/buildId 未知可留空，不为制作素材要求上传 TestFlight 或配置鉴权。
送审调用时继承已固定 appId、platform、version、buildNumber、buildId、语言/设备要求和输出目录，不自行换构建。
默认制作商店截图与文案；只请求截图、文案或视频时按请求收窄，清单明确未覆盖项。
读取 [素材清单契约](references/manifest.md)，确认既有清单、素材及版本关联是否可复用。
退出：制作范围、目标版本依据和输出位置明确；无法识别应用或版本时先完成独立准备并询问最少信息。

## 2. 确认功能、语言和素材缺口

读取 [本地化与文案](references/localization-copy.md)，从对应版本的实现和资源动态识别应用支持语言，映射商店 locale；不固定中英文，也不因全球发行生成全部语言。
核对已有最终素材、真实原图、截图自动化、模拟器/真机/macOS 窗口采集与真实 View 渲染入口。
沿用与目标版本一致的素材和已确认视觉；标出缺图、翻译、功能依据、权利或隐私问题。
退出：需要新增/更新的素材及语言/设备覆盖范围明确；未知功能不写入宣传承诺。

## 3. 生产真实截图与预览

读取 [截图生产](references/screenshot-production.md)。先复用有效文件，再自动采集；明确手动请求或自动化受阻时提供具体拍摄清单并等待文件。
新视觉方向先确认首张样图，确认后锁定图层版式扩展；已确认风格直接复用，局部修改只改对应图层。
截图主体来自真实 App UI；必要脱敏保留页面结构，不以概念图或虚构界面代替。新增 demo/截图入口等业务代码需要明确授权。
iOS 按 iPhone/iPad 实际设备族准备，macOS 按真实 Mac 窗口和对应尺寸要求准备；运行时核对 Apple 当前规格。
预览视频按用户要求制作与检查；只有方案或脚本不算已交付视频。
退出：本轮所需图片/视频实际存在，或 awaiting_manual_screenshots / awaiting_visual_confirmation / blocked 明确。

## 4. 制作文案与校验

按 [本地化与文案](references/localization-copy.md) 生成所需各语言字段，验证长度、链接和功能依据；保持与截图语言一致。
检查实际文件格式、尺寸、数量、文字溢出、UI 裁切、真实性及版权/隐私处理。缩略图/contact sheet 用于整体检查，最终成品抽检原图。
写入或更新 manifest，记录版本证据、文件 SHA-256、语言/设备覆盖、视觉确认、校验及阻塞。只完成部分素材时如实标为 partial。
退出：请求范围内实际产物可核验，未决事项有明确下一动作。

## 5. 交付与恢复

输出 manifest 路径、实际图片/视频/文案文件、版本依据、覆盖语言/设备、确认点和阻塞。
已有文件无变化时复用；目标版本、语言、画面或文案变化时只更新受影响部分并重新检查。
向送审任务返回本地素材与证据，由送审方核对构建匹配、上传和正式确认；素材完成不代表可送审或已提交。
不包含审核密码、私人联系人、凭据、预签名 URL；不触发 Git 发布或 Apple 账户写入。

维护或准备隔离验证时读取 [验证与交接](references/validation.md)。
