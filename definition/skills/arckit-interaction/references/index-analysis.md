# INDEX、归属与拆分

1. 读取正式 INDEX，按用户范围定位页面；探索操作另读 `_explorations/INDEX.md`。
2. 同一页面默认并入；正式一级业务目录表示页面/稳定路由。跨页关系写入 `_map/RELATIONS.md`。基础设施目录不受页面规则约束。
3. INDEX 每个页面一句摘要，列入口、说明及必要资源；保留文件行数作为导航提示。INDEX 超过 150 行时可按页面组拆二级索引，不改变页面归属。
4. 单文件超过 500 行、单页超过 8 个状态时评估职责拆分；报告受影响文件、拆分理由或保持原因。优先拆样式、行为、场景和组件，保证入口仍能连续运行。
5. 不为达到行数压缩成超长单行，不把入口改成占位骨架，不因目录形状主动重组不相关页面。
6. 正式变更更新对应 INDEX 行数、关系及状态覆盖；纯探索更新探索索引。记录 created/updated/deleted/reorganized 和依据。
