## 快速开始

### 1. 启动所有服务

```bash

cd /Users/zqs/Downloads/project/arckit/demo-business-system

# 运行测试脚本（检查服务状态并测试 API）

```

### 2. 访问演示系统

打开浏览器访问：**http://localhost:8082**

### 3. 使用智能客服

1. 点击页面右下角的 **紫色圆形按钮**（智能客服按钮）
2. 在弹出的对话窗口中输入问题
3. 智能客服会基于代码库进行回答
4. 可以使用快捷操作按钮快速提问

## 业务链路说明

### 1. 用户发起对话

```
用户点击智能客服按钮
    ↓
打开对话窗口
    ↓
用户输入问题
    ↓
POST /workshop/v1/user/feedbacks (创建反馈)
    ↓
workshop-api 创建反馈记录
```

### 2. 智能客服响应

```
用户发送消息
    ↓
POST /workshop/v2/user/feedbacks/:id/agent-message
    ↓
workshop-api 调用 OpenHands Agent
    ↓
Agent 检索本地代码仓库
    ↓
DeepSeek LLM 推理生成回答
    ↓
返回智能回答
```

### 3. 内部流转

```
智能客服无法回答
    ↓
反馈状态变为 "需要人工处理"
    ↓
通知团队成员
    ↓
人工介入处理
```

## 技术细节

### 对话窗口实现

本演示使用 **独立的 HTML 页面** 实现对话窗口，直接调用 workshop-api：

1. 用户输入问题
2. 调用 `POST /workshop/v1/user/feedbacks` 创建反馈
3. 调用 `POST /workshop/v2/user/feedbacks/:id/agent-message` 发送消息
4. OpenHands Agent 检索代码库并生成回答
5. 返回智能回答

### 认证流程

1. 请求头注入 `X-User-ID` 和 `X-User-Username`
2. workshop-api 从 header 获取用户身份
3. 完成用户认证和权限校验

### 数据流

```
用户输入 → 创建反馈 → 发送消息 → OpenHands Agent → DeepSeek LLM → 智能回答
```
