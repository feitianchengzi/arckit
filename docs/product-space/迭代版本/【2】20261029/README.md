## 产品定位

这是外部业务系统集成的SDK能力，不是独立系统。承担两项使命：仓库多模态答疑与Bug/需求分别收集后确认建卡；反馈全生命周期、持续补充与内部人员双向沟通。设计稿采用“示例宿主背景＋SDK浮层”，需求文档第11节为本版本优先约束。
