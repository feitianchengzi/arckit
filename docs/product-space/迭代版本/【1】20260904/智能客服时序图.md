# 智能客服端到端时序图

> 基于迭代 1 P1-P3 实际代码绘制。覆盖客户提问→Agent 回答→低置信结构化预填→提交反馈关联会话→客服回复→统一会话视图的完整链路。

## 1. 智能客服提问→回答（高置信直接回复）

```mermaid
sequenceDiagram
    participant C as 客户(SDK)
    participant API as workshop-api
    participant OH as OpenHands Agent
    participant DB as PostgreSQL

    C->>API: POST /agent-chats/messages {content, conversation_id?}
    API->>API: classifyAndRespond(白名单)
    alt 命中白名单(问候/能力咨询/提bug动作)
        API-->>C: 本地模板回复(confidence 0.88~0.95)
    else 放行
        API->>API: resolveProjectWorkspaceDir(projectID)
        API->>OH: ohCreateConversation(workingDir) + 发消息
        OH->>OH: LLM 基于代码推理 + 自评置信度
        OH-->>API: agent 回复 + [confidence:0.92]
        API->>API: parseAgentConfidence 剥离标注
        API->>DB: 存 agent_message_records
        API-->>C: {content, confidence:0.92, need_collect:false}
    end
```

## 2. 低置信→结构化预填→提交反馈关联会话（P1 会话衔接）

```mermaid
sequenceDiagram
    participant C as 客户(SDK)
    participant API as workshop-api
    participant OH as OpenHands Agent
    participant DB as PostgreSQL

    C->>API: POST /agent-chats/messages {content:"导出乱码"}
    API->>OH: callOpenHandsAgentForChat(workingDir)
    OH-->>API: 回复 + [confidence:0.60] + [summary]{position,phenomenon,expect}[/summary]
    API->>API: parseAgentConfidence → 0.60 < 0.75 → needCollect=true
    API->>API: parseAgentStructuredSummary → Structured{三字段}
    API->>DB: 存 agent_message_records(含 conversation_id)
    API-->>C: {content, confidence:0.60, need_collect:true, structured:{...}, conversation_id}

    Note over C: 前端 onNeedCollect 触发
    C->>C: formatStructuredFeedback(structured, question) → 预填表单
    C->>C: 显示 prefillNotice 友好提示
    C->>API: POST /feedbacks {content, conversation_id:"<standalone会话>"}
    API->>API: 创建 Feedback
    API->>DB: linkStandaloneConversationToFeedback(conv_id, feedback_id, project, user)
    Note over DB: agent_conversations.feedback_id 从 0 更新为新建反馈 ID
    API->>DB: createInitialFeedbackMessage(客户首条)
    API-->>C: {id, short_id}
    Note over C: 跳转 /chat?feedback=<id>，同一条会话延续
```

## 3. 客服回复→进会话→统一视图（P3 + P2）

```mermaid
sequenceDiagram
    participant Staff as 客服(Console)
    participant API as workshop-api
    participant DB as PostgreSQL
    participant C as 客户(SDK)

    Staff->>API: POST /feedbacks/:id/messages {content:"已修复"}
    API->>DB: createFeedbackMessageRecord(sender=developer)
    API->>DB: syncDeveloperReplyToAgentMessages(feedback)
    Note over API,DB: GetFeedbackConversations(feedback_id) 取会话<br/>写入 agent_message_records(sender=developer)
    API->>API: notifyProjectEvent(feedback.message.created)
    API-->>Staff: 201

    Note over C: 客户侧实时通道收到事件
    C->>API: GET /feedbacks/:id/conversation-messages
    API->>DB: aggregateConversationMessages(feedback_id)
    Note over API: 聚合 agent_message_records + feedback_messages<br/>按 created_at 排序<br/>去重 P3 复制的 developer 消息(content 相同)
    API-->>C: [{source:agent, customer}, {source:agent, agent}, {source:feedback, developer}]
    Note over C: FeedbackConversationPanel 渲染完整对话流
```

## 4. 降级路径（本地索引，OpenHands 不可用）

```mermaid
sequenceDiagram
    participant C as 客户(SDK)
    participant API as workshop-api
    participant DB as PostgreSQL

    C->>API: POST /agent-chats/messages {content}
    API->>API: getAgentServerByProject → nil（未配 OpenHands）
    API->>DB: searchCodeChunksBySQL(projectID, query)
    alt 有结果
        API-->>C: {content:代码片段拼接, confidence:0.7, need_collect:true}
        Note over API: 0.7 < 0.75 统一阈值触发 NeedCollect<br/>（本轮修复：与 unresolved 标记一致）
    else 无结果
        API-->>C: {content:未找到兜底, confidence:0, need_collect:true, structured:nil}
        Note over C: formatStructuredFeedback(undefined, question)<br/>退回提问原文（不编造三字段）
    end
```

## 5. 关键状态流转

```mermaid
stateDiagram-v2
    [*] --> Standalone咨询: 客户在提交页问智能客服
    Standalone咨询 --> 低置信: confidence < 0.75
    Standalone咨询 --> 高置信回复: confidence ≥ 0.9
    低置信 --> 结构化预填: onNeedCollect + formatStructuredFeedback
    结构化预填 --> 提交反馈: 客户确认
    提交反馈 --> 会话关联: linkStandaloneConversationToFeedback
    会话关联 --> 反馈跟进: 同一会话延续
    反馈跟进 --> 客服回复: developer message
    客服回复 --> 统一视图: aggregateConversationMessages
    统一视图 --> [*]: 客户看到完整对话流
```
