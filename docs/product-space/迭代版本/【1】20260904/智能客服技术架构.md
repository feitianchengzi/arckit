## 3. 会话总线数据模型（P1-P3）

```mermaid
erDiagram
    feedbacks ||--o{ feedback_messages : "客户首条+客服回复"
    feedbacks ||--o{ agent_conversations : "P1 关联"
    agent_conversations ||--o{ agent_message_records : "会话消息"
    customer_code_repos }o--|| feedbacks : "项目代码源"

    agent_conversations {
        string id PK
        uint feedback_id "0=standalone, N=关联反馈(P1)"
        uint project_id
        string custom_user_id "standalone 隔离"
    }

    agent_message_records {
        uint id PK
        string conversation_id
        uint feedback_id
        string sender_type "customer/agent/developer/system"
        string content
        float confidence
        string metadata "openhands_conversation_id 等"
    }

    feedback_messages {
        uint id PK
        uint feedback_id
        string sender_type "customer/developer/system"
        string content
    }
```

**P1 会话衔接**：提交反馈时 `agent_conversations.feedback_id` 从 0 → 新反馈 ID，咨询上下文延续。
**P3 客服回复进会话**：`syncDeveloperReplyToAgentMessages` 按 `feedback_id` 查 `agent_conversations`，写 `agent_message_records(sender=developer)`。
**P2 统一视图**：`aggregateConversationMessages` 聚合两表，按 `created_at` 排序，去重 P3 复制的 developer 消息（content 相同）。

## 4. per-project 工作区隔离（P1）

```mermaid
flowchart LR
    REQ[OpenHands 建会话] --> RES[resolveProjectWorkspaceDir]
    RES --> P1{RepoPath 存在?}
    P1 -->|是| R1[workingDir = RepoPath<br/>显式本地路径]
    P1 -->|否| P2{ohClonedRepoDir 存在?}
    P2 -->|是| R2[workingDir = OH_REPO_ROOT/projectID<br/>sync clone 落点]
    P2 -->|否| R3[workingDir = OH_WORKSPACE_DIR<br/>兜底]
    R1 --> OH[OpenHands 容器]
    R2 --> OH
    R3 --> OH
```

**容器卷共享**：workshop-api 和 OpenHands 容器挂载同一 `OH_REPO_ROOT` 卷，clone 的代码 Agent 才能读。

## 5. 检索双层架构

```mermaid
graph LR
    Q[客户提问] --> RET[RetrieveHandler / processWithAgent]
    RET --> L1[本地代码索引<br/>searchCodeChunksBySQL]
    RET --> L2[OpenHands Agent<br/>callOpenHandsAgentForChat]
    L1 --> DB[(knowledge_sources<br/>code_index.code_chunks)]
    L2 --> OH[OpenHands<br/>实时探索 workingDir 代码]
    L1 -->|SQL 关键词检索| HITS[RetrievalHit]
    L2 -->|LLM 引用文件路径| HITS
    HITS --> MERGE[合并结果 + 置信度]
```

- **本地索引**：`customer_code_repos` sync 后 `runCodeIndexPipeline` 建索引，SQL 关键词检索
- **OpenHands**：Agent 在 `workingDir` 实时探索代码，LLM 推理
- **降级**：OpenHands 不可用 → 只走本地索引（confidence 0.7）
