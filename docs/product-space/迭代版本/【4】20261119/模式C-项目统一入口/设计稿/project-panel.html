新建规则

该页面不在本设计稿范围

本稿聚焦合并后的「项目」入口、idea 阶段探讨、面板积压卡片与自动化规则；点击侧栏「项目」继续评审。

创建项目

先选择项目所处阶段；idea 阶段可先不配仓库，探讨成熟后立项时补配。

立项确认

讨论结论已通过，立项后进入面板管理阶段。

    沟通空间

    过程性行为：议题 / 观点 / 结论

    评审路径
    1. 导航只剩一个「项目」入口（原 Product + Idea 合并）；列表页顶部阶段 tab：idea 阶段 / 面板管理，同一项目可在两阶段间可逆切换。
    2. 「创建项目」：选阶段；idea 阶段不出现仓库字段，选面板管理阶段才展开按需配置仓库。
    3. 打开 idea 阶段项目：项目沟通空间常驻（参与者头像栈 + ＋成员选择器 + Agent 初步分析），无需先开卡片。
    4. 点「＋ 添加成员」→ 项目成员选择器点选林晓（入分母）→ 起草结论 1/2 → 投赞成 2/2 → 显性「通过结论」→ 拆解草稿预览。
    5. 右侧「立项」动作卡：结论通过后可用 → 确认立项 → 阶段转面板管理、首批卡片进入积压、事件 project.solidified，自动切入面板。
    6. 面板页：积压 chip 居首且不进七态计数；三数据来源条（Workshop 任务源 / GitHub Issues / Feedback），反馈来源可「进入积压」。
    7. 卡片详情：未开启讨论只有「开启讨论」（徽标未讨论）；开启后沟通空间（卡片宿主）+ 搁置/取消搁置；未讨论直接执行或验收弹「未经讨论决策」风险确认。
    8. 状态流转覆盖全七态 + 积压：进入待办 / 开始执行 / 提交评审 / 评审通过 / 打回修改 / 验收 / 标记阻塞 / 解除阻塞 / 取消；accepted、cancelled 为终态。
    9. 「自动化规则」子页：项目级规则列表（触发 → 动作）启停 + 新建；卡片进积压、反馈到达、状态变更、结论通过会真实触发规则并累计「已触发 N 次」（事件 rule.fired）。
    10. 面板头部「回到 idea 阶段探讨」可逆回退；idea 阶段再次「立项」可回到面板。
