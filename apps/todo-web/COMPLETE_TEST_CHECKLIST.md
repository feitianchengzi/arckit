## 步骤 5: 常见问题检查

### 5.1 API 调用失败

**症状**：浏览器控制台显示网络错误或 404/500 错误

**检查**:
1. 后端服务是否正在运行：`curl http://localhost:8081/todo/v1/public/health`
2. 前端环境变量是否正确：`cat frontend/.env.local`
3. CORS 配置：后端 `.env` 中是否有 `CORS_ALLOW_ORIGINS=http://localhost:3000`

**解决方案**:
- 如果后端未运行，启动后端服务
- 如果 CORS 错误，检查后端 CORS 配置
- 如果 404 错误，检查 API 端点路径是否正确

### 5.2 登录后无法跳转

**症状**：登录成功后仍然停留在登录页面

**检查**:
1. middleware.ts 是否正确配置
2. authStore 中的 `isAuthenticated` 是否为 `true`
3. localStorage 中是否有 `auth_token`

**解决方案**:
- 清除 localStorage 后重新登录
- 检查浏览器控制台的错误信息
- 验证 middleware.ts 的逻辑

### 5.3 状态更新不生效

**症状**：更改任务状态后，UI 没有更新

**检查**:
1. React Query 缓存是否失效
2. API 请求是否成功
3. 状态映射是否正确（前端 status vs 后端 state）

**解决方案**:
- 检查浏览器 Network 面板，确认 API 请求成功
- 刷新页面查看状态是否已保存
- 检查 `taskMapper.ts` 中的状态映射

### 5.4 子任务不显示

**症状**：创建子任务后，父任务详情页面不显示子任务

**检查**:
1. 任务详情 API 是否返回 `children` 字段
2. `taskMapper.ts` 是否正确转换了子任务
3. 前端是否正确渲染了 `todo.children`

**解决方案**:
- 检查浏览器 Network 面板，查看任务详情 API 响应
- 验证 `taskToTodo` 函数是否正确处理了 `children` 字段
- 检查 SubtaskList 组件是否正确接收和渲染数据
