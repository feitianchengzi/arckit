## ⚠️ 已知问题和限制

### 后端不支持的功能

1. **任务历史**：状态历史功能会显示为空（后端不支持）
2. **邀请列表**：无法查看已生成的邀请列表（后端不支持）
3. **删除邀请**：无法删除已生成的邀请（后端不支持）

### 数据字段缺失

1. **创建者和执行者**：可能只显示 ID，不显示用户名（后端可能不返回用户对象）
2. **子任务**：需要前端根据 father_id 构建层级关系

## 🔍 调试技巧

### 查看 API 请求

1. 打开浏览器开发者工具（F12）
2. 切换到 Network 面板
3. 筛选 `XHR` 或 `Fetch` 请求
4. 查看请求 URL、请求体、响应数据

### 常见错误处理

**401 未授权**：
- 检查 localStorage 中是否有 `dev_user_id` 和 `dev_username`
- 检查 API 请求 Header 中是否有 `X-User-ID`

**404 未找到**：
- 检查 API 路由是否正确
- 检查后端是否有对应的接口

**400 请求参数错误**：
- 检查请求体格式
- 检查必填字段是否都有值

**500 服务器错误**：
- 查看后端日志
- 检查数据库连接
- 检查后端环境变量配置
