# 交互设计规范

**Feature**: 待办管理系统  
**Created**: 2024-12-19  
**Platform**: Web

## 1. 交互模式 (Interaction Patterns)

### 导航模式

**Web 导航**:
- **模式**: 单页应用（SPA）路由导航
- **实现**: 客户端路由，使用 History API
- **转场动画**: 淡入淡出，时长 `DesignTokens.Animation.standard`
- **面包屑导航**: 用于深层页面，显示当前位置

**页面结构**:
- **顶部导航栏**: 固定顶部，包含 Logo、主导航、用户菜单
- **侧边栏** (桌面端): 可折叠，显示项目列表
- **主内容区**: 动态内容区域

### 选择模式
- **单选**: 点击选择，选中状态使用 `DesignTokens.Colors.primary` 背景
- **多选**: 复选框模式，支持全选/取消全选
- **范围选择**: 列表项支持 Shift+点击进行范围选择

### 编辑模式
- **进入方式**: 点击"编辑"按钮或双击列表项
- **退出方式**: 
  - 保存按钮: 保存更改并退出
  - 取消按钮: 放弃更改并退出
  - ESC 键: 取消编辑
- **取消处理**: 显示确认对话框（如有未保存更改）

### 评论功能
- **添加评论**: 在评论输入框中输入内容，点击发布或按 Ctrl+Enter 提交
- **编辑评论**: 点击自己的评论可编辑，保存后更新
- **删除评论**: 点击自己的评论可删除，需确认
- **@提及**: 支持@提及成员，被提及的成员会收到通知
- **快速评论**: 从成员气泡中触发，自动填充@成员并聚焦输入框

### 删除模式
- **确认方式**: 二次确认对话框
- **删除操作**: 
  - 单个删除: 点击删除按钮 → 确认对话框 → 执行删除
  - 批量删除: 选择多个 → 批量操作栏 → 确认对话框 → 执行删除
- **反馈**: 删除成功后显示 Toast 提示，支持撤销操作（5秒内）

### 列表操作
- **排序**: 支持按创建时间、更新时间、优先级排序
- **筛选**: 支持按状态、执行人、创建人筛选
- **搜索**: 实时搜索，输入后 300ms 延迟触发搜索
- **分页**: 每页显示 20 条，支持无限滚动或分页器

### 悬停气泡
- **触发**: 鼠标悬停在成员项上，延迟 300ms 后显示气泡
- **内容**: 显示该成员参与的待办事项列表，包含待办标题、状态
- **交互**: 
  - 点击气泡中的待办项 → 跳转到待办详情页面
  - 点击快速评论按钮 → 跳转到待办详情，自动填充@成员并聚焦评论输入框
- **隐藏**: 鼠标移出成员项或气泡区域时隐藏
- **位置**: 自动计算位置，避免超出视口

## 2. 手势操作 (Gestures)

### Web 平台交互

| 输入方式 | 操作 | 响应 | 反馈 |
|---------|------|------|------|
| 鼠标点击 | 点击按钮、链接 | 立即响应 | 视觉反馈（按下效果） |
| 鼠标悬停 | 悬停在可交互元素上 | 显示悬停状态 | 光标变为 pointer，背景色变化 |
| 右键菜单 | 右键点击列表项 | 显示上下文菜单 | 菜单动画显示 |
| 拖拽 | 拖拽待办项 | 改变顺序或状态 | 拖拽预览，放置区域高亮 |
| 键盘快捷键 | Ctrl/Cmd + 键 | 执行快捷操作 | 操作提示 Toast |
| 双击 | 双击列表项 | 进入编辑模式 | 编辑界面展开 |

### 键盘快捷键

| 快捷键 | 操作 | 说明 |
|--------|------|------|
| Ctrl/Cmd + N | 新建待办 | 快速创建 |
| Ctrl/Cmd + K | 全局搜索 | 打开搜索框 |
| Ctrl/Cmd + S | 保存 | 保存当前编辑 |
| ESC | 取消/关闭 | 关闭模态框、取消编辑 |
| Enter | 确认 | 提交表单、确认操作 |
| Delete/Backspace | 删除 | 删除选中项（需确认） |

## 3. 动画效果 (Animations)

### 界面转场
- **类型**: 淡入淡出 + 轻微位移
- **时长**: `DesignTokens.Animation.standard`
- **缓动**: `DesignTokens.Animation.easeInOut`

### 元素动画
- **淡入淡出**: 列表项出现/消失，使用 `DesignTokens.Animation.standard`
- **缩放**: 按钮按下效果，缩放至 0.95，时长 `DesignTokens.Animation.fast`
- **位移**: 拖拽时跟随鼠标，使用 `DesignTokens.Animation.fast`

### 加载动画
- **类型**: 骨架屏（Skeleton Screen）或旋转指示器
- **位置**: 内容区域居中或顶部
- **样式**: 
  - 骨架屏: 灰色占位块，脉冲动画
  - 加载指示器: 圆形旋转，使用 `DesignTokens.Colors.primary`

### 状态变更动画
- **待办状态切换**: 状态标签颜色过渡，时长 `DesignTokens.Animation.fast`
- **列表项更新**: 高亮显示 2 秒后恢复，使用 `DesignTokens.Colors.warning` 背景

## 4. 反馈机制 (Feedback)

### 视觉反馈
- **按钮按下**: 缩放 0.95，背景色加深，时长 `DesignTokens.Animation.fast`
- **选中状态**: 背景色 `DesignTokens.Colors.primary`，透明度 0.1
- **悬停状态**: 背景色变化，光标 pointer，阴影加深
- **焦点状态**: 边框颜色 `DesignTokens.Colors.primary`，宽度 2px

### 触觉反馈（移动端）
- **轻触**: 点击操作（如支持）
- **中等强度**: 重要操作确认
- **重触**: 错误操作

### 声音反馈（可选）
- **操作确认**: 成功操作提示音（可选）
- **错误提示**: 错误操作提示音（可选）

### 文本反馈

**成功消息**:
- **样式**: Toast 提示，绿色背景 `DesignTokens.Colors.success`，白色文字
- **位置**: 右上角
- **时长**: 3 秒自动消失

**错误消息**:
- **样式**: Toast 提示或内联错误，红色背景 `DesignTokens.Colors.error`，白色文字
- **位置**: 表单字段下方或 Toast
- **时长**: 5 秒自动消失或手动关闭

**警告消息**:
- **样式**: Toast 提示，橙色背景 `DesignTokens.Colors.warning`，深色文字
- **位置**: 右上角
- **时长**: 4 秒自动消失

**信息消息**:
- **样式**: Toast 提示，蓝色背景 `DesignTokens.Colors.info`，白色文字
- **位置**: 右上角
- **时长**: 3 秒自动消失

## 5. 交互响应时间

| 交互类型 | 响应时间要求 | 说明 |
|---------|-------------|------|
| 点击/触摸响应 | <100ms | 立即视觉反馈，操作执行可异步 |
| 页面加载 | <500ms | 首屏内容显示 |
| 数据刷新 | <1s | 列表数据更新 |
| 搜索结果 | <300ms | 搜索输入后延迟触发 |
| 表单提交 | <500ms | 提交按钮响应 |
| 模态框显示 | <200ms | 动画开始时间 |

## 6. 错误处理

### 错误提示方式
- **Toast**: 全局错误、成功提示，不影响页面布局
- **Alert**: 重要错误、需要用户确认的操作
- **Inline Error**: 表单验证错误，显示在字段下方
- **页面级错误**: 加载失败、网络错误，显示错误页面

### 错误恢复
- **重试机制**: 网络错误提供"重试"按钮
- **降级方案**: 数据加载失败时显示缓存数据（如有）
- **用户引导**: 错误提示包含解决建议或帮助链接

### 表单验证
- **实时验证**: 输入时验证（失焦后显示错误）
- **提交验证**: 提交时验证所有字段
- **错误提示**: 红色文字，图标提示，字段边框红色

## 7. 响应式设计

### 断点定义
- **移动端**: < 768px
- **平板端**: 768px - 1024px
- **桌面端**: > 1024px

### 布局适配
- **移动端**: 单栏布局，侧边栏折叠为抽屉菜单
- **平板端**: 双栏布局，侧边栏可折叠
- **桌面端**: 三栏布局，侧边栏、主内容、详情面板

### 交互适配
- **移动端**: 触摸优化，按钮最小 44x44px
- **平板端**: 支持触摸和鼠标
- **桌面端**: 鼠标和键盘优化
