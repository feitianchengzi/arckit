📝 创建和编辑：
• 在待办文本中输入语法：- [ ] 任务 @执行人 #标签
• 按 Enter 在当前待办下方创建新待办
• 输入 @ 自动显示执行人列表（点击选择）
• 输入 # 自动显示标签列表（点击选择）
• 点击文本直接编辑内容
💡 试试：在任意待办中按 Enter，会在下方创建新待办
⌨️ 键盘操作：
• Space 切换待办状态（选中待办时）
• Alt+↑ / Alt+↓ 重排序
• Tab 缩进（创建子待办）
• Shift+Tab 取消缩进
• Backspace / Delete 删除待办（待办为空时）
• Ctrl+D / Cmd+D 删除待办
🖱️ 鼠标操作：
• 点击复选框切换状态
• 拖拽 ⋮⋮ 图标重排序
• 悬停待办显示删除按钮 ×，点击删除
• 点击 @执行人 或 #标签 编辑
💡 快捷键设计说明：
• 使用 Enter 而非 Ctrl+Enter 创建待办，避免与系统快捷键冲突
• 使用 Alt+↑/↓ 重排序，避免与文本编辑快捷键冲突
• 所有操作支持键盘和鼠标两种方式
核心价值体现：在文本编辑器中直接创建和管理待办，无需跳转。所有核心交互统一在一个编辑器中： 语法化创建、键盘优先操作、待办编辑整理、待办分发、状态管理、重排序等功能。

🎯 设计优化思考：
1. 项目切换优化：
• 问题：现有设计需要跳转到项目列表页面，打断工作流
• 优化：顶部项目选择器，支持快速切换项目，编辑器状态保持（光标位置、编辑内容）
• 价值：无需跳转，在编辑器内即可切换项目，保持流畅的编辑体验
2. 成员管理集成：
• 问题：成员管理与待办管理分离，@执行人时需要手动输入或跳转
• 优化：输入 @ 时自动显示当前项目的成员列表，支持键盘选择
• 价值：成员管理无缝集成到编辑器体验中，无需离开编辑器
3. 待办创建流程优化：
• 问题：现有设计需要跳转到创建待办页面，填写表单，再跳转回来
• 优化：在编辑器中直接输入语法创建待办，按 Enter 即可，无需跳转
• 价值：消除跳转，保持编辑器的流畅体验，符合核心价值主张
4. 列表式展示问题：
• 问题：列表式待办不利于快速整理和AI介入，需要点击进入详情页编辑
• 优化：编辑器式展示，所有待办在同一视图中，支持直接编辑、拖拽排序、批量操作
• 价值：充分发挥编辑器管理待办的核心价值，支持快速整理和AI处理
5. 侧边栏功能整合：
• 问题：侧边栏功能（项目列表、成员管理）与编辑器分离，需要跳转
• 优化：侧边栏作为导航和快速访问，主内容区始终是编辑器，功能通过编辑器语法和快捷键访问
• 价值：保持编辑器为核心，周边功能作为辅助，不打断编辑体验
完整系统设计：将编辑器式待办管理整合到完整系统中，通过项目选择器、成员管理集成、编辑器核心体验等方式， 消除跳转，保持流畅的编辑体验。所有周边功能（项目、成员）都围绕编辑器核心价值进行优化。
