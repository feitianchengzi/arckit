   - ✅ API 请求都携带了 `X-User-ID` Header

2. **Console 面板**：

3. **Application → Local Storage**：

## ⚠️ 常见问题

### 问题：API 调用 404

**原因**：后端路由可能不同，或功能未实现

**解决**：检查后端 API 文档，确认端点路径

### 问题：CORS 错误

**解决**：确保后端 `.env` 中设置了：
```env
CORS_ALLOW_ORIGINS=http://localhost:3000
```

### 问题：状态更新不生效

**解决**：
1. 刷新页面查看是否已保存
2. 检查 Network 面板，确认 API 请求成功
3. 检查浏览器控制台是否有错误
