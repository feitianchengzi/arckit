# 标签和优先级功能改进文档

## 📋 概述

本次更新实现了类似 GitHub 的标签和优先级管理系统，提供了完整的标签管理功能和直观的优先级选择器。

## ✨ 新增功能

### 1. 🏷️ 标签功能增强

#### 1.1 修复颜色 Bug
- **问题**：之前标签颜色可能缺少通道，只有 3 通道（6位 RGB）
- **解决方案**：自动识别并转换 6 位 RGB 格式为 8 位 ARGB 格式
- **位置**：`frontend/src/lib/utils/tagParser.ts`
  
```typescript
// 现在支持两种格式：
// - "[Bug](#ff0000)" → 自动转换为 "[Bug](#ffff0000)"
// - "[Add](#ffabc101)" → 保持不变
```

#### 1.2 标签管理器（新增）
- **位置**：`frontend/src/components/features/TagManager.tsx`
- **功能**：
  - ✅ 查看项目所有标签
  - ✅ 编辑标签名称（带验证）
  - ✅ 删除标签（智能同步）
    - 从项目中删除标签
    - **自动从当前任务中移除该标签**
    - 立即更新到后端
  - ✅ 标签预览（自动生成一致的颜色）
  - ✅ 友好的交互体验（确认对话框、加载状态等）

**使用方式**：
- 在任务详情页的标签区域点击"管理"按钮
- 弹出标签管理器对话框
- 可直接编辑或删除项目标签
- **删除标签时会自动从当前任务中移除并保存**

#### 1.3 增强的标签选择器
- **位置**：`frontend/src/components/features/TagSelector.tsx`
- **新增功能**：
  - ✅ "管理"按钮 - 打开标签管理器
  - ✅ "新建"按钮 - 创建新标签并添加到任务
  - ✅ 标签列表 - 显示所有可用标签
  - ✅ 一键添加/移除 - 点击标签即可切换

**操作说明**：
1. **添加标签到任务**：点击"可用标签"列表中的标签
2. **移除标签**：再次点击已选中的标签，或在"已选标签"区域点击删除按钮
3. **新增项目标签**：点击"新建"按钮，输入名称并选择颜色
4. **管理项目标签**：点击"管理"按钮，可编辑或删除已有标签

### 2. 🎯 优先级选择器（新增）

#### 2.1 优先级组件
- **位置**：`frontend/src/components/features/PrioritySelector.tsx`
- **设计理念**：参考 GitHub 的优先级样式
- **优先级定义**：
  - 🔴 **最高** (0) - 紧急且重要，需要立即处理
  - 🟠 **高** (1) - 重要任务，优先处理
  - 🟡 **中** (2) - 正常优先级
  - 🟢 **低** (3) - 不紧急，可以延后处理
  - ⚪ **无** (null) - 未设置优先级

#### 2.2 组件特性
- ✅ 下拉选择样式
- ✅ 带图标和颜色的视觉标识
- ✅ 详细的优先级描述
- ✅ 支持三种尺寸（sm / md / lg）
- ✅ 提供只读徽章组件（PriorityBadge）

**使用示例**：
```tsx
// 可编辑的选择器
<PrioritySelector
  value={task.priority}
  onChange={(priority) => updateTask({ priority })}
  disabled={false}
  size="md"
/>

// 只读徽章
<PriorityBadge value={task.priority} size="sm" />
```

## 🔧 技术实现

### 标签格式
```
格式：[名称](#颜色)
示例：[Bug](#ffff0000),[Feature](#ff00ff00)

颜色支持：
- 8位ARGB：#ffff0000（推荐）
- 6位RGB：#ff0000（自动转换为 #ffff0000）
```

### API 调用
```typescript
// 获取项目标签
tagsApi.listByProject(projectId)

// 创建标签
tagsApi.create(projectId, { project_id, name })

// 更新标签
tagsApi.update(tagId, { name })

// 删除标签
tagsApi.delete(tagId)

// 更新任务标签
updateTask({ tags: "[Bug](#ffff0000),[Feature](#ff00ff00)" })

// 更新任务优先级
updateTask({ priority: 0 }) // 0=最高, 1=高, 2=中, 3=低, null=无
```

## 📝 注意事项

### 标签
1. **颜色格式**：虽然支持 6 位 RGB，但建议统一使用 8 位 ARGB
2. **标签删除**：删除标签不会影响已使用该标签的任务，任务仍会显示标签
3. **重名检查**：同一项目内标签名称必须唯一（不区分大小写）

### 优先级
1. **数值含义**：数字越小优先级越高（0 最高，3 最低）
2. **可选字段**：优先级是可选的，可以不设置
3. **类型转换**：需要注意 `null` vs `undefined` 的处理
