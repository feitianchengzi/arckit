# Release 多项目协作工作台 · 可交互探索稿

直接打开 `index.html`，无需安装或启动服务。整个目录可独立复制。当前版本使用独立的 v3 浏览器存储，刷新保留操作记录；右上角可以重置。

所有项目、已有工作区、命令输出、Git、Agent、应用启动、workflow、发布和部署均为模拟。没有访问真实账户、执行命令或修改生产页面。

## 本次修订

依据 [现有交互调研](research/current-interaction.md)，保留实际 ArcOrbit 的导航与顶部「产品集 / 查看 / 管理」。本原型预置已有项目和本地工作区，未新增项目创建、仓库关联、目录绑定或环境安装流程。

- 产品集决定观察范围；顶部切换产品集后重置为「项目集全部」。
- 全部模式聚合项目快捷操作和构建记录。新建终端等未明确目标的动作先选择已有项目；点击有归属的操作按钮直接使用该项目。
- 在全部模式选中记录后，内容区进入该记录的项目工作台，顶部仍保持「项目集全部」，局部上下文明确显示所选项目，可返回全部记录。
- 单项目模式直接使用其现有本地工作区。
- Git、构建、产物、终端、Agent、发布及环境记录分别保持项目归属。终端输入草稿、Agent 草稿和页面滚动按项目保存。
- 构建、Agent 回答、workflow 和部署的异步完成只写回启动时的项目。切换范围不会移动执行目录或消息。
- 「本机活动」保留全部项目的活动，包括当前产品集之外的项目。显式打开外部活动时展示其固定上下文，不修改任何产品集成员。

## 推荐体验

1. **跨项目操作**：选 ArcOrbit 构建，立即从顶部「查看」切到 Workshop Todo；可同时构建、开终端或输入对话。通过本机活动或结果提示返回 ArcOrbit。
2. **全部范围处理失败**：从初始 ArcOrbit 失败记录点击「分析失败」，附加该记录日志，应用修复，检查 Diff，暂存提交并重新构建。
3. **复用已有配置**：从项目快捷操作直接启动开发版或构建。命令与目录沿用预置的已有关联。
4. **终端与对话归属**：在 A 输入草稿后切换 B，输入另一份草稿，再切回 A。会话目录和内容分别恢复。
5. **发布与部署**：Workshop Todo → 版本发布 → 准备发布 → 选择已有固定引用 → 运行发布构建 → 远端草稿 → 确认发布 → 环境部署。部署弹窗可选择失败场景，验证旧版本保留、重试和回退。
6. **产品集外活动**：ArcOrbit 构建期间切换到「Web 产品」，从本机活动返回 ArcOrbit 的构建。Web 产品的成员保持不变。

右上角「体验指南」提供前三类核心场景入口。

## 终端与 Git

终端支持多标签、当前标签输入历史、清屏、折叠、最大化、拖动高度，以及 Ctrl/Cmd + 反引号。输入 `help` 查看当前项目的模拟命令。执行器控制的会话只读，可另建手动终端。不能输入任意真实命令。

Git 支持文件选择、Diff、逐文件暂存、提交、推送确认和干净工作区分支切换。源码推送不创建 tag，也不自动触发发布。Agent 修改仅留在工作区。

## 发布事实与限制

本地构建记录保存开始时的项目、目录、命令、分支、commit、未提交修改标记及产物位置。正式发布演示使用预置的远端固定引用；不会把本地未提交或未进入该引用的修改自动包含进去。

远端构建成功仅产生发布草稿。用户确认发布后才更新版本记录；环境部署成功后才更新当前运行版本。模拟健康检查失败时，旧环境版本保持不变。仅演示当前测试环境，不配置生产环境。

页面刷新会将未完成的模拟构建标记中断，停止模拟实例，并保留记录与日志；不会假装浏览器刷新后仍有真实进程在运行。正式实现需由 Desktop 进程管理器依据真实进程身份恢复。

左侧其他模块及自动领取控件只保留原应用壳视觉；顶部产品集管理可模拟更改展示成员，不改变现有本地绑定和自动执行授权。
