# Login - 交互规范

## 交互策略

### 核心任务

应用启动时先恢复 Workshop 认证会话。未登录用户在独立登录页面完成邮箱或手机号验证码登录；认证成功后进入 Automation Command Center。登录页面是未登录状态下唯一可交互的主页面，Automation Workspace 不在其后提供可绕过的操作入口。

### 用户场景

1. 用户首次启动 Runtime Desktop，没有可恢复会话，需要使用邮箱验证码登录后开始同步项目与待办。
2. 用户退出登录后仍停留在应用内，需要回到登录页面重新建立远端身份。
3. 用户已有可刷新会话，启动时不需要重复输入，系统恢复成功后直接进入 Command Center。
4. 验证码发送或登录失败，用户需要保留已输入目标并在页面内修正、重试。

### 主路径

1. 应用启动并在登录页面展示会话恢复状态，主进程读取认证状态。
2. 会话已认证或可刷新时，系统进入 Command Center 并开始同步当前用户项目与待办。
3. 会话未登录时，页面展示邮箱/手机号选择、目标地址、验证码、发送验证码和登录动作。
4. 用户发送验证码；服务端确认后，重发按钮进入 60 秒冷却，目标地址和验证码仍可编辑。
5. 用户提交验证码；认证成功后页面退出登录门禁并进入 Command Center，同步状态立即可见。

### 决策点

- 认证状态恢复完成前不展示可操作的 Automation Workspace，避免用户把空项目快照误认为已同步事实。
- `logged_out` 进入登录页面；`authenticated` 与可刷新的会话进入 Command Center；`expired` 保留只读 Command Center，并通过账号入口要求重新登录。
- 邮箱与手机号是互斥验证码类型。切换类型更新输入标签和格式校验，不清除另一字段之外的页面反馈。
- 登录成功是离开页面的唯一业务路径；未登录页面没有关闭、返回或跳过登录动作。

### 信息揭示

- 首屏优先展示产品标识、登录用途、认证状态和验证码表单。
- access token、refresh token、精确过期时间、服务响应正文和本地 Automation Workspace 不在登录页面展示。
- 服务根地址、调试认证和 Codex 代理留在登录后的高级设置，不进入默认登录路径。

### 状态流

`启动 → 恢复会话 → 已认证 → Command Center`

`启动 → 恢复会话 → 未登录 → 发送验证码 → 验证码已发送 → 提交验证码 → 登录中 → Command Center`

`发送验证码或登录失败 → 原位错误反馈 → 修正目标或验证码 → 重试`

`Command Center → 退出登录 → 清除远端快照 → Login`

### 反馈与恢复

- 会话恢复期间展示单一进度状态，不闪现空的 Command Center。
- 发送验证码、提交登录分别锁定各自动作；验证码发送成功后展示脱敏目标和倒计时。
- 校验和服务端错误显示在表单内并保留目标地址与验证码，切换验证码类型后错误反馈仍保持可见，直到下一次提交。
- 登录成功后立即进入 Command Center；项目同步失败不回退登录，只在工作区显示同步恢复状态。

### 输入输出边界

- 输入只有验证码类型、邮箱或手机号和验证码。
- 输出只有验证码发送反馈、归一化认证状态和进入 Command Center 的导航结果。
- Renderer 不能读取 token 或指定认证服务路径；所有认证请求通过 main 进程的受限 IPC 完成。

### 线框投影要求

`default.html` 投影会话恢复、未登录入口、验证码已发送和登录失败四个状态。每个状态保持独立触发条件、桌面设备框、组件清单和交互行为；Automation Workspace 只以登录成功后的导航目标出现，不作为登录页背景或可关闭区域。

## 页面状态

| 状态 | 触发条件 | data-kit 关键控件 |
|------|---------|-----------------|
| 会话恢复 | 应用启动，认证状态尚未返回 | ProgressView、VStack |
| 未登录入口 | 主进程确认没有有效或可刷新会话 | Form、Picker、TextField、Button |
| 验证码已发送 | 认证服务确认发送成功 | Form、倒计时 Button、inline status |
| 登录失败 | 输入校验或认证服务拒绝登录 | Form、inline error、Button |

## 导航流程

### 进入方式

- 应用启动始终先进入会话恢复状态；确认未登录后留在 Login。
- 用户从已登录设置退出后进入 Login。

### 页面内导航

- 邮箱与手机号分段选择只改变表单类型，不产生新页面。

### 离开方式

- 已认证会话恢复成功或验证码登录成功后进入 Automation Command Center。
- Login 没有关闭、返回和跳过入口。

## 交互行为

### 验证码类型

- **选择邮箱：** 目标字段使用邮箱标签与校验。
- **选择手机号：** 目标字段使用手机号标签与校验。

### 发送验证码

- **点击：** 校验当前目标并发送验证码；请求期间只锁定发送动作。
- **成功：** 展示脱敏目标并开始 60 秒重发冷却。
- **失败：** 保留输入并显示原位错误。

### 登录

- **点击：** 校验目标和验证码并提交；请求期间只锁定登录动作。
- **成功：** 清空验证码，进入 Command Center 并开始同步。
- **失败：** 保留目标与验证码并显示原位错误。

## 弹窗/对话框

Login 不使用可关闭 Sheet 或 Alert。错误、冷却和进行中反馈均在页面表单内完成。

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
|---------|---------|---------|
| 目标格式无效 | 目标字段附近的原位错误 | 修正目标后重试 |
| 验证码格式无效 | 验证码字段附近的原位错误 | 修正验证码后重试 |
| 验证码发送失败 | 表单状态区 | 保留目标并重新发送 |
| 登录被拒绝 | 表单状态区 | 保留输入并重新登录 |
| 网络不可用 | 表单状态区 | 网络恢复后重试原动作 |

## 加载策略

| 场景 | 策略 |
|------|------|
| 会话恢复 | 全页单一 ProgressView，不展示 Automation Workspace |
| 发送验证码 | 只锁定发送按钮并显示动作文本 |
| 提交登录 | 只锁定登录按钮并显示动作文本 |
