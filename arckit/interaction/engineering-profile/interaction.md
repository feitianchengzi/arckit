# Engineering 场景技能 - 交互规范

## 交互策略

Engineering 帮助用户决定 Chat 与 Automation 可以使用哪些技能。首版按本机全局场景配置，不编辑团队 Domain Profile 或 State Model。Chat 输入框技能入口直达 Chat 场景，返回保留当前会话与草稿。

## 页面与主路径

1. 顶部 Chat / Automation 切换显示当前生效范围与 revision。
2. 展示真实技能列表，支持搜索、来源过滤、查看名称/描述/路径与使用方式。
3. catalog 技能可选择直接发现、按需使用、禁用；其他目录技能可直接发现或禁用，也可替换；替换选择另一个真实技能并原子保存。
4. 选择本地 skill 文件夹导入目录引用，验证失败显示原因；不复制或修改用户技能。
5. Automation 核心显示锁定；Chat 核心作为 Loop 配套开关，官方来源不可替换。
6. 保存成功提示生效时机；重试加载处理读取失败，revision 冲突提示刷新。

## 状态与反馈

- 加载：禁用 mutation 并显示正在读取。
- 内容：独立场景、直接发现与按需数量、来源及路径、核心锁定和搜索。
- 选择本地来源：系统目录选择器；取消不写入，缺少 SKILL.md 显示错误。
- 替换：选择候选，排除保护核心；成功更新列表，不覆盖来源。
- 保存失败：保留当前界面，显示原因与重试入口。
- 空列表/无搜索结果：明确区分未安装与过滤无匹配。
- Chat 说明：下一条消息应用；历史已加载指令不会被清除。
- Automation 说明：下一次运行应用；当前运行保持原集合。

## 来源与边界

规范来源：`arckit/spec/agentic-software-development/arcorbit-scene-skills.md`。
页面线框：`default.html`。环境检查迁移依据同一规格，无旧副本备份交互。

按需入口默认直接发现，可禁用；不能设为按需使用自身。Chat 默认只直接发现按需入口。安装/更新/清理在活动任务结束后经确认执行，场景切换不搬动安装目录。
