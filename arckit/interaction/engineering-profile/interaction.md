# Engineering 内置 Skills - 交互规范

## 交互策略

Engineering 帮助用户高效检查和调整 ArcOrbit 内置 Skills 在 Chat 与 Automation 中的使用方式。页面以已安装内置集合为唯一输入，在首屏同时呈现场景、数量摘要、检索控件和紧凑列表，使用户无需逐张卡片浏览即可理解当前配置。

用户自行安装的用户级、项目级、on-demand catalog 或本地目录 Skills 不进入页面的列表、计数、搜索、错误和操作。页面不提供来源筛选、本地导入、第三方替换或删除；这些 Skills 继续由 Codex 自身管理。

主路径是选择场景、浏览或筛选内置 Skill、在行内调整使用方式并接收即时保存结果。Chat 入口固定打开 Chat 场景，返回保持原会话和草稿。Automation 核心保持可见且锁定，帮助用户理解不可修改的运行约束。

## 页面结构与信息层级

1. 页面标题直接说明“内置 Skills”，副说明声明非内置 Skills 不显示。
2. Chat / Automation 分段控件与生效时机位于同一紧凑控制区。
3. 内置总数、直接发现、按需使用和已停用数量构成单行摘要；切换场景时同步更新。
4. 搜索、状态筛选、刷新和恢复默认位于同一工具栏。
5. 列表使用名称与说明、安装状态、使用方式三列；安装路径按需展开，不占用默认阅读高度。
6. 状态行显示配置 revision、安装内容版本、保存结果和当前筛选命中数。

## 主路径

1. 用户进入页面，系统读取可信内置 catalog 和两个场景的配置。
2. 系统默认显示 Automation，摘要和列表只包含 `builtin:*` 条目。
3. 用户切换 Chat 或 Automation，系统在本地切换投影，不重新读取 catalog。
4. 用户搜索名称或说明，或按直接发现、按需使用、已停用筛选；列表与命中数即时更新。
5. 用户改变某行使用方式，系统携带当前 revision 保存该内置 Skill。
6. 保存成功后系统刷新摘要和 revision，并说明下一条 Chat 消息或下一次 Automation Run 生效。

## 使用方式

- 直接发现：该内置 Skill 的受信安装目录加入场景 Agent roots。
- 按需使用：该内置 Skill 只进入显式调用范围。缺少 qualifiedName 的条目不提供此选项。
- 已停用：该内置 Skill 不提供给当前场景。
- `arcforge-on-demand` 不提供“按需使用”自身的选项。
- Automation 的 `using-arckit` 使用方式锁定为直接发现，控件禁用并显示“Automation 必需”。
- Chat 的官方核心可调整，页面仍标记“官方核心”。

## 搜索、筛选与空状态

搜索匹配内置 Skill 的名称和说明，不匹配安装路径。状态筛选按当前场景的使用方式过滤，可与搜索叠加。

筛选无匹配时，页面显示“没有匹配的内置 Skill”，并提示清除搜索或状态筛选。页面不建议添加本地 Skill。可信内置集合为空或尚未安装时属于加载错误，不作为普通筛选空状态。

## 保存与恢复

- 保存期间所有使用方式、场景切换、刷新和恢复默认操作禁用，页面设置忙碌状态。
- 保存成功原位更新列表、摘要、revision 和生效时机，不滚动到页面顶部。
- 保存失败保留当前场景、搜索、筛选和既有列表，在状态区显示错误；用户可重试同一选择或刷新。
- revision 冲突提示刷新后重新操作，不覆盖其他窗口的配置。
- 恢复默认只重置当前场景的内置 Skills；不改写另一个场景或任何用户自行安装的 Skill。
- 刷新失败保留最后一次成功列表，不清空用户的搜索和筛选。

## 加载与错误

首次加载期间列表显示读取状态，mutation 不可用。内置安装尚未完成、更新待确认或内容冲突时，页面显示来自受信 catalog 的错误，并引导用户前往环境检查处理；页面不显示用户 Skill 路径或错误。

Renderer 对 snapshot 再次按 `source === builtin` 过滤。不合约 payload 中的用户、项目、本地和其他 catalog 条目不会出现在列表、命中数或操作控件中。

## 键盘与窄窗口

场景按钮使用 tab 语义并暴露选中状态。搜索、状态筛选、刷新、恢复默认、路径展开和每行使用方式均可通过键盘到达并具有可见焦点。

窄窗口下摘要折为两列，列表表头隐藏；安装状态与使用方式保持靠近对应 Skill。更窄窗口改为单列，控件不产生横向滚动。

## 导航边界

Chat 输入框附近的“内置 Skills”入口进入 Engineering 并选择 Chat。用户返回 Chat 时保留原会话、草稿和阅读位置。Engineering 不创建 Automation Run，不修改 Project/Case，不触发安装、更新或清理。
