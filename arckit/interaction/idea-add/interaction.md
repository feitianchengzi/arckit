# 添加 Idea

## 交互策略

从空白或材料建立可恢复 Idea，在可编辑资料区与对话区协作完成接入。

两区操作同一事实。Agent 提案可审阅修改，直接输入不被迟到结果覆盖。确认参数后执行外部变更，返回不丢进度。

正式 Idea 保存在关联项目目录的 `arckit/product/`；临时记录显示“录入未完成 · 仅本机”。正式完成要求 GitHub 仓库、本地 Git 目录和资料落盘，共享结果另行显示。Idea 列表从临时记录与当前产品集关联目录共同恢复。

## 页面结构与主路径

- 选择起点：点击添加 Idea。界面展示添加 Idea；创建固定本机环境；原材料保持在原路径。
- 协作整理：Idea 已保存。界面展示资料区｜对话区；直接编辑或发送消息，双方看到同一修订事实。
- 审阅建议：Agent 生成资料提案。界面展示建议待采纳；基础修订过期时提示重新生成；不覆盖人工输入。
- 确认接入：准备关联或新建项目。界面展示接入方案；确认精确方案；组织与仓库权限分别校验。
- 执行中：方案已确认。界面展示正在接入；工具输入和结果显示在对话中；成功步骤不重复。
- 接入完成：GitHub 仓库、本地目录和正式记录均已核对。界面展示已关联产品；不自动把产品标记推进中，不自动启动 Automation。
- 失败与待核对：部分步骤失败或响应不明。界面展示进度已保留；不盲目重复外部创建，仍能修改本机资料。
- 中断恢复：重启或停止后返回。界面展示继续这个 Idea；继续原场景线程，未确认操作不自动执行。

## 状态与恢复

对话和可编辑区并列，窄窗口上下排列。使用既有 Conversation Surface 和 Composer，保留输入、停止、权限、工具活动和滚动位置。

加载与错误就地显示；返回和重启保留本机草稿，错误不伪装成成功。远端项目操作遵守当前账号权限；产品目录不触发 Setup。

## 投影

`default.html` 中的独立状态块覆盖上述主路径、决定与恢复；控件沿用 Desktop 视觉规范。
