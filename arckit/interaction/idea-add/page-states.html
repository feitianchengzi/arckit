正式目录：~/Developer/hoewo/ScreenRecord（示例）

复制材料、保留来源；不复制 .git、依赖缓存、凭据和符号链接。不覆盖冲突文件，不自动提交或推送。

对话

你：正式工作目录现在选择的合适吗？

Agent：你选的是“选择其他工作目录”，目标是左侧显示的 ~/Developer/hoewo/ScreenRecord。它将作为对应 GitHub 的本地仓库，材料会从 Downloads 复制过来并保留原件。这个位置便于其他开发工具使用；接入不会自动提交或上传源码。

目录确认前：先选择你希望长期使用的位置，当前还没有正式目标。
