# Product 详情

## 交互策略

查看并维护产品状态、理念、资产与项目关系，从同一产品进入已有能力页面。

产品状态由明确记录提供。编辑先本机保存，Git 共享单独展示差异并确认。

正式 Idea 保存在关联项目目录的 `arckit/product/`；临时记录显示“录入未完成 · 仅本机”。正式完成要求 GitHub 仓库、本地 Git 目录和资料落盘，共享结果另行显示。Idea 列表从临时记录与当前产品集关联目录共同恢复。

## 页面结构与主路径

- 产品总览：从目录选择产品。界面展示产品名 · 尚未设置 · 仅本机；导航携带项目身份，返回保留产品选择。
- 编辑资料：用户直接编辑或采纳 Agent 建议。界面展示保存产品资料；保存校验修订号；不改变任务或执行状态。
- 共享确认：本机资料已修改。界面展示共享到 GitHub；确认后显示实际 Git 结果。
- 共享冲突：本机与远端都修改。界面展示两份资料都已保留；未选择不覆盖，不强推。
- 来源或权限失败：记录损坏或 Git 不可访问。界面展示产品资料暂时无法读取；不以空白记录覆盖原资料。

## 状态与恢复

加载与错误就地显示；返回和重启保留本机草稿，错误不伪装成成功。远端项目操作遵守当前账号权限；产品目录不触发 Setup。

## 投影

`default.html` 中的独立状态块覆盖上述主路径、决定与恢复；控件沿用 Desktop 视觉规范。
