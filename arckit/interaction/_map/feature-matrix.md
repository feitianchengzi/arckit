# Interaction Feature Matrix

| Page | Status | Core task | Projected states |
|---|---|---|---|
| `automation-workspace/` | ✅ | 先建立当前用户的项目来源，再通过确定性条件式领取形成跨项目串行队列，并在人工或事实异常时进入对应工作台 | 启动同步、待命、项目范围切换、自动执行、人工介入、完成续接、空队列、写回失败；领取冲突、启动失败、安全停止、外部状态变化、多活动任务、任务源异常与会话失效；人工处理、只读审查 |
| `task-browser/` | ✅ | 在当前项目范围内浏览七种服务器任务状态，检查项目与 Runtime 关联并执行有权限的人工状态处置 | 待处理列表、待评审确认、进行中任务、已完成验收、已阻塞恢复、取消确认、当前范围为空、同步或版本冲突 |
