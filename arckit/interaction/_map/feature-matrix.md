# Interaction Feature Matrix

| Page | Status | Core task | Projected states |
|---|---|---|---|
| `login/` | ✅ | 启动时恢复 Workshop 会话；未登录时通过不可绕过的验证码门禁建立当前用户项目来源 | 会话恢复、未登录入口、验证码已发送、登录失败 |
| `automation-workspace/` | ✅ | 登录后通过全局领取总闸和项目授权形成确定性串行队列；每个待办使用跨内部 thread 聚合的轻量消息流，并提供分项 Token 用量与非阻断软异常观察 | 已登录账号摘要、会话失效；启动同步、待命、自动领取配置缺口、项目范围切换、自动执行、人工介入、完成续接、空队列、写回失败；领取冲突、启动失败、安全停止、外部状态变化、多活动任务；待办级消息审查、人工处理、用量诊断 |
| `task-browser/` | ✅ | 在当前项目范围内浏览七种服务器任务状态，检查项目与 Runtime 关联并执行有权限的人工状态处置 | 待处理列表、待评审确认、进行中任务、已完成验收、已阻塞恢复、取消确认、当前范围为空、同步或版本冲突 |
