## 可操作路径

| 入口 | 操作结果 | 恢复 |
|---|---|---|
| 标题旁转为待办 | 编辑标题/描述，展开完整来源，保存后原会话出现主待办身份 | 取消保留草稿；已转换禁用再次转换 |
| 消息下新建待办 | 带入此消息；保存后原对话增加卡片 | 点卡片进入独立待办对话，返回原会话恢复草稿 |
| 输入框新建待办 | 轻表单直接记录待办 | 不消耗未发送消息、不替换当前主待办 |
| 会话列表选择已有待办 | 搜索、选择、建立或恢复关联对话 | 空结果保留搜索；取消回到原页面 |
| 待办身份条 | 模态查看标题、描述、状态 | 返回/Esc 关闭 |
| 分析/执行＋发送 | 本地追加明确区分的模拟反馈 | 已有 Automation 执行占用时禁用发送 |
| 探索工具创建失败 | 下次保存显示错误，表单内容保留 | 再次提交成功；提交期间防重复 |
| 探索工具重置 | 清除当前候选样本状态 | 正式原型不受影响 |

表单和选择器使用覆盖全窗口的原生 HTML dialog，阻止背景输入。取消/Esc 关闭并恢复触发焦点；提交期间等待结果。窄于 760px 会话列表为右侧抽屉，选择或 Esc 关闭。消息输入支持 Ctrl/⌘+Enter，输入法组合期间不触发快捷发送。会话草稿、阅读位置和关联保存在独立 localStorage key `arcorbit-exploration-chat-todo-v1`。

## 模拟边界

静态样本摘要不是 AI 自动提炼。没有真实 Agent、远端待办 API、同步、线程迁移或执行结果；不以示例反馈更新业务状态。工作区选择、跨项目创建、真正的暂停交接、失权/删除、离线恢复、创建成功但绑定失败在主题说明中定义候选期望，本原型未实现。导航除 Chat 外是定位背景，不声称完整产品可操作。

视觉使用正式 light Token 和 ConversationSurface 规则。新增轻关联条与卡片只是本探索组合。原生桌面窗口控件不在浏览器内伪造。
