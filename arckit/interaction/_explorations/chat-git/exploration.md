## 可操作候选

[比较入口](options/compare/default.html)：场景工具切换承载方式、状态、侧栏宽度和明暗主题。两种候选使用同样的项目、文件和提交样本，无网络或真实 Git 操作。

| 候选 | 路径 | 收益与代价 |
|---|---|---|
| 右侧栏 | 摘要 → 右栏 Git 概览 → 文件差异／提交内容 → 返回概览 → 会话列表 | 复用现有详情空间，宽窗口中央对话仍可见；暂时隐藏列表，220px 下长路径与差异较拥挤 |
| 窗口内弹窗 | 摘要 → 模态 Git 概览 → 文件差异／提交内容 → 关闭 | 可用阅读宽度较大；查看时暂时遮住对话，背景不可操作，关闭回原摘要 |

建议复用右侧栏，依据是既有详情承载规则及对话可见性；差异的阅读宽度仍须在采纳时明确（在原容器中阅读，或按需扩大）。这属于建议，不是正式决定。候选分别保留返回和 Esc 关闭、焦点恢复；不新增提交、Pull、Push、Merge 或自动 Fetch。

## 两方案共同的状态语义

| 状态 | 摘要／详情表达 |
|---|---|
| 未提交 | 文件数按路径去重；详情区分未暂存、已暂存、未跟踪、暂存后再次修改 |
| 本地干净 | 弱化 Git 入口；只断言本地没有修改，不宣称实时远端同步 |
| 待推送／待拉取 | ↑／↓ 附明确名称与数量；基于本地远端跟踪缓存 |
| 双方新增 | 显示双方计数与“分歧”，相关提交分别可达 |
| 冲突 | 明确冲突数；只读查看当前内容和冲突标记，不提供合并编辑 |
| 读取中／过期／失败 | 状态明确，旧结果作为上次结果；可重读，不替换为干净 |
| 远端未检查／获取失败 | 独立于本地状态；展示获取动作、成功时间及失败，失败不生成成功时间 |
| 无仓库／未绑定 | 低干扰说明实际原因，保留入口；不模拟创建仓库成功 |

点击摘要不改变组的折叠状态。组头宽度不足时摘要换行，项目名保留阅读空间。工作区归属在详情中持续可见；其他项目摘要也不切换当前会话。文件与提交差异均只读、按需加载；生产应覆盖二进制、大文件、读取失败、没有上游以及重绑定失效，不由样本推断成功。
