# ArcOrbit Product Feedback Center - 交互规范

## 交互策略

### 核心任务

用户登录 ArcOrbit 后，直接向固定 Feedback Project 107 提交 ArcOrbit 产品问题或建议，并查看同一 Workshop 账户下自己的反馈状态、沟通记录和未读变化。用户不接触 Project ID 或 API Key 配置。

### 用户场景

- 用户在任意主要工作页面点击顶部命令栏“产品反馈”，直接进入提交反馈。
- 用户在同一反馈中心切换到“我的反馈”跟进记录。
- 反馈回复或状态变化时，入口显示未读数量；没有未读时不显示角标。
- 未登录时入口转到账户登录；SDK 加载或认证失败时保留当前模式并允许重试。

### 主路径

1. 用户点击顶部命令栏“产品反馈”。
2. ArcOrbit 校验当前 Workshop 登录身份。
3. 独立反馈中心加载固定 SDK 页面，以内置 Project 107 和项目专用 Key 完成配置。
4. 默认进入“提交反馈”；用户可在“提交反馈”和“我的反馈”间切换且不重载 SDK 文档。
5. 后台未读刷新只读取当前 SDK 文档的权威未读数，不重载健康文档，也不清除进行中的反馈正文。
6. 用户关闭反馈中心后返回原 ArcOrbit 页面和观察范围。

### 决策点

- “提交反馈 / 我的反馈”只存在于反馈中心内部，不拆成两个入口。
- 产品反馈没有配置页；Project ID、API Key 和通知开关均由产品代码拥有。
- 未登录时只恢复 Workshop 账户；不存在普通用户可处理的“未配置”状态。
- Project ID 固定为 107，通知固定开启。

### 信息揭示与状态流

窗口标题始终标识“ArcOrbit 产品反馈”。主窗口入口在未读数大于 0 时显示数字角标，超过 99 显示 `99+`。状态流为：入口校验 → SDK 加载 → 提交反馈或我的反馈；未登录 → 账户登录；SDK 未就绪、认证失败或网络失败 → 保留模式并重试或关闭；退出登录 → 关闭反馈中心并清除旧账户角标。

### 输入输出边界

反馈正文、附件和消息由 Feedback SDK 处理。ArcOrbit 只提供内置 Project ID 107、内置 Key、当前稳定用户身份和模式切换，不读取或复制反馈内容。后台同步通过复用同一健康 SDK 文档保持进行中草稿；用户明确关闭反馈中心、切换账户、触发重试或由 SDK 完成提交时，草稿按对应上下文生命周期处理。主 Renderer 只接收归一化未读整数，不接收凭据、反馈正文或用户 ID。

## 页面状态

| 状态 | 触发条件 | 关键控件 |
|---|---|---|
| SDK 加载 | 已登录，固定 SDK 页面尚未 ready | 模式分段控件、加载提示、关闭 |
| 可用内容 | SDK ready 且内置配置成功 | 提交反馈、我的反馈、SDK 内容区 |
| 需要登录 | 未登录或身份不可解析 | 原因说明、打开账户、关闭 |
| SDK 失败 | 文档、readiness、认证或网络失败 | 脱敏错误、重试、关闭 |
| 存在未读 | SDK 返回大于 0 的当前用户未读数 | 主窗口入口数字角标 |

## 交互行为

### 模式切换

- **点击提交反馈：** 打开 SDK submit 模式；已在该模式时不重复配置。
- **点击我的反馈：** 打开 SDK status 模式；保留同一 SDK 页面和身份。
- **后台同步：** submit/status 路由属于同一健康 SDK 文档；未读轮询和未读事件复查不触发页面重载，不打断输入焦点或清空正文。

### 未读角标

- 登录后后台准备受限 SDK 页面并读取 `getUnreadCount()`，不主动显示反馈中心。
- 只接受固定 SDK 文档内、同 origin、同 window 且类型为 `feedback-sdk:unread-changed` 的信号，再读取权威未读数。
- 0 隐藏，1–99 显示数字，超过 99 显示 `99+`；读取不修改已读状态。
- 退出登录或身份失效时清除角标；新账户使用 fresh identity 重新配置 SDK。

### 恢复动作

- **打开账户设置：** 聚焦 Workshop 登录区段。
- **重试：** 重新检查 readiness 或加载固定 SDK 页面，不暴露完整配置。

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
|---|---|---|
| 未登录/身份不可解析 | 需要登录状态 | 打开账户设置 |
| 内置 Key 缺失 | SDK 不可用 | 要求更新客户端构建；普通用户不可配置 |
| SDK 未 ready 或方法缺失 | SDK 失败状态 | 重试或关闭 |
| 认证/网络失败 | SDK 失败状态 | 脱敏错误、重试或关闭 |

## 加载策略

| 场景 | 策略 |
|---|---|
| 首次打开 | 校验身份后加载固定 SDK V2 HTTPS 页面和内置配置 |
| 模式切换 | 复用页面，只调用对应 open action |
| 后台未读刷新 | 复用已配置的健康 SDK 文档，只调用未读查询；路径已进入 submit/status 时仍不重载 |
| 文档加载失败 | 用户触发后重新加载固定页面 |
| 身份切换或显式重试 | 销毁旧配置上下文并重新加载固定页面 |
| 关闭后再开 | fresh-read 当前身份并创建健康窗口 |
