# Idea 列表

## 交互策略

展示当前设备保存的 Idea，并提供继续整理、接入和查看已关联产品的入口。

列表显示接入事实与更新时间；接入进度不等于产品业务状态。添加过程在独立页面完成。

正式 Idea 保存在关联项目目录的 `arckit/product/`；临时记录显示“录入未完成 · 仅本机”。正式完成要求 GitHub 仓库、本地 Git 目录和资料落盘，共享结果另行显示。Idea 列表从临时记录与当前产品集关联目录共同恢复。

## 页面结构与主路径

- Idea 列表：进入 Idea。界面展示Idea · 添加 Idea；打开同一 Idea 的添加页和会话。
- 尚无 Idea：当前设备没有 Idea。界面展示把想法放进 ArcOrbit；无文件夹也能开始；不会自动创建远端项目。
- 已关联产品：接入得到共享项目回执。界面展示产品已关联；正式资料进入本地仓库，原会话身份保持。

## 状态与恢复

加载与错误就地显示；返回和重启保留本机草稿，错误不伪装成成功。远端项目操作遵守当前账号权限；产品目录不触发 Setup。

## 投影

`default.html` 中的独立状态块覆盖上述主路径、决定与恢复；控件沿用 Desktop 视觉规范。
