# Product 列表

## 交互策略

浏览全部可访问项目与本机 Idea，查找并进入产品长期上下文。

搜索和显式状态筛选只影响当前列表；未设置状态不推断。添加 Idea 打开独立页面。

正式 Idea 保存在关联项目目录的 `arckit/product/`；临时记录显示“录入未完成 · 仅本机”。正式完成要求 GitHub 仓库、本地 Git 目录和资料落盘，共享结果另行显示。Idea 列表从临时记录与当前产品集关联目录共同恢复。

## 页面结构与主路径

- 产品目录：Catalog 读取完成。界面展示产品 · 搜索 · 状态：全部；打开产品详情；添加 Idea。
- 空目录：没有可访问项目或本机 Idea。界面展示从一个想法开始；创建后进入添加页。
- 来源不可用：共享 Catalog 读取失败。界面展示共享项目暂时无法刷新；重试来源，保留已有记录。

## 状态与恢复

加载与错误就地显示；返回和重启保留本机草稿，错误不伪装成成功。远端项目操作遵守当前账号权限；产品目录不触发 Setup。

## 投影

`page-states.html` 中的辅助状态块覆盖上述主路径、决定与恢复；控件沿用 Desktop 视觉规范。

## 全局上下文原型

`default.html` 使用 `_shared/global-context.js`、`global-shell.js` 与 `context-pages.js`，连续演示 CONVENTIONS.md 定义的产品范围、对象选择、草稿和统一顶部能力；页面专项状态图保留在 `page-states.html`，其旧窗口壳仅作历史示意。原型保存及运行状态均为浏览器本地模拟，服务调用和页面专项深层操作的验证边界沿用各自说明。
