# 五入口交互覆盖

本轮只维护交互原型与同域说明，生产源码只用于核对。所有写入、邀请、同步、Auto 和发布动作均为本地样本。

| 领域 | 原型能力 | 参考与边界 |
|---|---|---|
| 主导航 | 原应用 SVG；Chat/项目/团队/工程；底部设置；名称提示 | Logo 复制自 runtime/arcorbit/build/icon.svg |
| Chat | 项目分组、对话/待办 Tab、标题行新建、底部新项目、全高综合栏 | 延续同一工作身份和 Auto 接力；不展示产品集或独立搜索、新建栏 |
| 项目 | Idea 编辑、计划与工作、成果、发布草稿/检查/交付预览、运维异常转工作、反馈、产品集 | 发布运维仅交互预埋，不声明现有部署和监控接入 |
| 组织 | 组织创建/编辑/选择、角色与成员、加入/离开/删除、成员×项目关系矩阵 | 对照 arcorbit-organization-management.md；当前样本不验证服务端鉴权或分页 |
| 项目治理 | 项目角色职责、邀请、直接添加同组织成员、成员管理、目录绑定、产品集、Auto 参与 | 项目权限独立；目录不触发真实文件访问；不发出真实邀请 |
| 邀请 | 角色、期限、次数、一次性代码与链接、复制、加入失败 | 不虚构邀请历史与撤销 API；样本代码不创建真实成员关系 |
| 工程 | 两个场景、搜索/筛选/计数、三种模式、安装详情、刷新/恢复默认、失败/冲突 | 对照 engineering-surface.mjs；固定示例清单，不探测真实安装；核心能力锁定 |
| 设置 | 登录/验证码/退出、主题、两套模型与推理级别、YOLO、任务源三种认证、代理、同步、运行定位、产品反馈 | 对照 renderer/index.html 与 account-capabilities.md；凭据只保留已配置标记，反馈不发送 |

## 实际验证

`verify-suite.cjs` 使用隔离 Electron 窗口真实点击 DOM；报告与截图输出系统临时目录。覆盖五入口、项目生命周期、关系矩阵、直接加成员、邀请结果、目录不授权 Auto、成员权限界面、Skill 场景隔离与核心锁定、设置保存、凭据不持久化、主题、登录门禁、失败重试、配置冲突和 1440/1024/760/390px 无整页横向溢出。

这次新增页面的检查不等于重新验收所有历史 Chat/Auto 分支。真实流式 Agent、跨人并发、服务端权限与分页、远端文件、发布/监控接入仍需生产实现与独立测试；旧核心脚本记录不冒充本轮新壳验证。
