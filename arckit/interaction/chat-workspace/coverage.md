# 场景覆盖与复核

适用范围：用户选定的 Chat + Work + Auto，及 Idea、多项目、待办、反馈、项目团队。以下是原型覆盖，不是生产测试报告。

| 场景 | 入口与操作 | 预期结果 / 恢复 | 复核 |
|---|---|---|---|
| 图标导航 | 悬停或键盘聚焦图标 | 显示名称，工作空间统一入口 | verify-navigation.cjs |
| 列表双视角 | 对话/待办 Tab 切换 | 列表变化，工作和草稿保留 | verify-navigation.cjs |
| 标题往返滚动 | 溢出行悬停/聚焦 → 离开 | 仅标题移动，离开复位；减少动态效果禁用 | verify-navigation.cjs |
| 列表收起与窄窗 | 标题列表按钮 | 桌面收起、窄窗覆盖展开 | verify-navigation.cjs |
| 产品集聚合 | 面板选择全部 → 项目分组列表 | 选工作不改变查看范围 | verify-worksets.cjs |
| 范围外工作 | 收窄/清空产品集 | 保留中央草稿与工作，明确返回入口 | verify-worksets.cjs |
| 明确创建归属 | 全部项目 → 新建待办 → 选择项目 | 不隐式改产品集，工作归属固定 | verify-worksets.cjs |
| 产品集管理 | 修改成员 → 保存 → 刷新 | 空集合法，折叠与范围持久化 | verify-worksets.cjs |
| 聚合反馈/独立团队 | 跨项目回复、团队选择并返回 | 写入正确项目，恢复原工作 | verify-worksets.cjs |
| 首条消息建工作 | 新对话 → 输入 → 发送 | 同一编号和摘要，无转待办步骤 | 自动化 |
| 空白草稿 | 新对话 → 不提交 | 不新增待办 | 自动化 |
| 首发失败 | 工具：下次失败 → 发送 → 重试 | 草稿保留，重试只创建一个 | 自动化 |
| 无 Chat 的待办 | 直接创建待办 | 目标/负责人存在，没有伪造消息 | 自动化 |
| 自动整理 | 填入示例 → 发送 | 更新目标和约束，来源可查看 | 自动化 |
| 普通输入 | 发送任意文本 | 作为补充保留，不伪装结构化理解 | 自动化 |
| 人工纠正 | 右侧待办 → 编辑 | 修订号改变，旧检查失效 | 自动化 |
| 版本冲突 | 冲突场景 → 编辑并保存 | 查看新版本、保留草稿后合并 | 自动化 |
| 分配工作 | 负责人 → 选择项目成员 | 改负责人，不启动 Auto | 可操作；常规分配未单独断言 |
| 启动授权 | 交给 Auto → 确认 | 开始当前工作本轮执行 | 自动化 |
| 运行中补充 | Auto 时输入并发送 | 待采用提示，边界后纳入工作 | 自动化 |
| 暂停接管 | 暂停并讨论 → 推进一轮 | 回执前不能编辑，回执后可接管 | 自动化 |
| 产品取舍 | 需要决定 → 选择 → 确认 | 记录约束，继续同一工作 | 自动化 |
| 执行失败 | 失败场景 → 推进一轮 | 显示原因，检查后恢复到暂停 | 自动化 |
| 外部等待 | 等待场景 → 条件恢复 | 不自动启动，明确继续 | 自动化 |
| 他人占用 | 占用场景 → 编辑 | 提示执行者，阻止改写 | 自动化 |
| 同项目排队 | 启动第一件 → 创建并启动第二件 | 等待执行位置，可取消 | 自动化 |
| 后台推进 | 启动 → 切换项目 → 推进一轮 | 原任务继续，选择不被抢走 | 自动化 |
| 跨项目定位 | 运行概况 → 原工作 | 先恢复项目再打开同一工作 | 自动化 |
| 自动演进 | 普通入口启动 Auto | 无工具栏也能进入决策状态 | 自动化 |
| 重启恢复 | Auto 中刷新 | 原工作暂停，上下文保留 | 自动化 |
| 成果检查 | 待验收 → 检查 → 勾选 → 验收 | 未检查不能验收 | 自动化 |
| 导出成果失败/重试 | 样例成果 → 开始/失败/完成 | 根据已确认选择显示失败路径 | 自动化 |
| 退回调整 | 成果 → 提出调整 | 暂停，后续明确继续 | 可操作；本轮未单独断言 |
| 重新打开 | 已验收 → 重新打开 | 同一身份，旧检查失效 | 自动化 |
| 归档恢复 | 待办详情归档 → 列表已归档 → 恢复 | 日常列表移除，内容不丢失 | 自动化 |
| 项目草稿隔离 | 输入草稿 → 切换两次 | 原项目草稿恢复 | 自动化 |
| 目录缺口 | 轻记 → 文件/Git | 不展示拾光文件 | 自动化 |
| 文件引用 | 文件 → 选择 → 引用到对话 | 追加草稿，不清空输入 | 自动化 |
| Git 差异 | Git → 选择 → 暂存 → 已暂存 | 本地模拟状态一致 | 自动化 |
| 文件错误 | 文件失败场景 → 重试 | 仅局部恢复 | 自动化 |
| Idea 新项目 | 新建项目 → 名称/Idea → 创建 | 项目与第一件探索工作连续 | 自动化 |
| Idea 草稿 | 输入 → 关闭 → 再打开 | 名称与 Idea 保留 | 可操作；本轮未单独断言 |
| 待办列表 | 搜索 / 我负责 / 已归档 | 当前项目的同一对象 | 自动化覆盖列表及归档 |
| 反馈回复 | 反馈 → 回复 → 提交 | 保留回复记录 | 自动化 |
| 反馈转工作 | 反馈 → 编辑目标/负责人 → 创建 | 带来源，不自动 Chat/Auto | 自动化 |
| 反馈关联已有 | 反馈 → 关联待办 | 只列当前项目 | 可操作；本轮未单独断言 |
| 反馈闭环 | 关联工作实际推进/验收 → 反馈解决 | 验收前不可解决，之后人工关闭 | 自动化完整链 |
| 反馈忽略/重开 | 忽略 → 恢复；已解决 → 重开 | 状态与回复分别保留 | 可操作；本轮未单独断言 |
| 邀请成员 | 团队 → 邮箱/角色 → 创建 | 只是待接受邀请，成员数不增加 | 自动化 |
| 邀请撤销/重复 | 再次邀请同邮箱 / 撤销 | 防重复，可撤销 | 可操作；本轮未单独断言 |
| 角色维护 | 团队 → 管理 → 保存角色 | 当前项目成员角色更新 | 自动化 |
| 移出和交接 | 成员管理 → 移出 → 选择接替者 | 待办转交后移出，不丢历史 | 自动化 |
| 普通成员 | 普通成员场景 → 邀请 | 提示需要管理员 | 自动化 |
| 只读权限 | 只读场景 → 输入/提交 | 不写入，草稿保留 | 自动化 |
| 离线恢复 | 离线场景 → 提交 → 重连 → 重试 | 同一输入继续 | 自动化 |
| 刷新失败 | 刷新失败场景 → 重新读取 | 上次快照与失败分开表达 | 可操作；本轮未单独断言 |
| 输入法/键盘 | IME Enter、弹窗 Esc | 不误发、焦点恢复 | 自动化 |
| 综合栏键盘 | Tab 聚焦标签，左右/Home/End | 切换标签且焦点跟随 | 可操作；本轮未单独断言 |
| 长内容与窄窗 | 长内容场景，1440/1024/760/390 | 无页面横溢，综合栏可覆盖 | 自动化 + 截图复核 |
| 明暗与主产品页面 | 普通入口 / 暗色 | 无探索工具，右栏顶到顶部 | 自动化 + 截图复核 |

运行产物输出系统临时目录，可通过 ARCORBIT_TEST_OUTPUT 指定；不把报告/截图写为正式事实。截图人工复核覆盖桌面长标题、暗色、窄窗综合栏及项目管理视图。

未接入的真实能力：Agent 语义、真实 thread/Case/Loop、文件系统与 Git、真实邀请和用户回复、服务端冲突与幂等、多设备同步、发布运维、组织治理和工程个性化。此范围不可用本地模拟冒充完成。
