# Task Browser - 交互规范

## 交互策略

### 核心任务

用户在 Work 面板内使用七种服务器状态筛选 Task Browser 投影，在顶部产品集观察范围内创建或编辑明确产品归属的待办，并通过左侧完整列表和右侧 Inspector 检查单项任务及其项目和 Runtime 关联、执行权限允许的状态操作。Task Browser 是 Work 的同屏内容区，不是独立主导航页面；它负责团队待办维护、观察和人工状态处置，不承担自动队列控制。

### 用户场景

1. 用户在顶部选择“项目集全部”，再选择 Work 的“待处理”筛选，在同屏列表与 Inspector 中查看哪些任务已经获得自动执行资格，以及它们在跨项目队列中的顺序。
2. 用户从单个项目的“待评审”进入，阅读任务详情并明确确认其可以进入待处理队列。
3. 用户从“进行中”进入，打开关联 Runtime；任务没有本地 Runtime 或状态异常时进入 Automation Recovery Center。
4. 用户从“已完成”进入，在右侧 Inspector 审查结果、全部验收问题及进展，提出新的验收问题；没有未解决问题且证据充分时可以将任务标记为已验收。
5. 用户从“已验收”进入，Inspector 显示验收通过和“当前没有待处理的验收问题”，不提供问题 Composer。已取消任务保持只读，阻塞任务根据恢复条件返回待处理或恢复原运行。
6. 用户操作任务时发现服务器版本已变化。页面不覆盖新状态，而是刷新该任务并解释冲突。
7. 用户创建或编辑待办时先确认产品。执行人、父待办和标签只显示该产品的数据；优先级使用有意义的固定档位，标签可在表单内选择、创建、编辑或删除。

### 主路径

1. Work 读取顶部产品集观察范围和面板内任务状态；直接进入 Work 时默认使用“项目集全部 / 待处理”。
2. Work 保留同一应用壳，左侧只高亮 Work；当前项目范围显示在顶部产品集控件，七状态显示在 Work 内容区筛选条。
3. 页面按 `project_id + state` 拉取任务，并在状态筛选条下方同屏渲染左侧任务列表与右侧 Inspector。
4. 首次进入、切换状态或切换产品范围时自动选中结果中的首条任务；用户选择其他任务时只更新右侧 Inspector。Inspector 展示内容、所属项目、本地工作区、自动执行资格、关联 Runtime、状态历史和可用动作。
5. 用户触发“创建待办”时，表单以当前有效单产品范围或 Workset 首个产品为默认值；切换产品立即重置并替换执行人、父待办和标签候选。编辑待办时产品不可跨项变更，所有候选固定来自任务所属产品。
6. 用户执行创建、编辑或状态操作时，页面先确认权限与当前服务器版本，再提交服务器请求。
7. 服务器确认后，任务从当前筛选结果移出或更新；状态计数、Command Center 队列和 Inspector 同步刷新。
8. 用户切换到 Automation 时保留顶部产品范围；从 Runtime 入口进入时可直接返回对应运行。

### 决策点

- 顶部产品集范围和 Work 面板状态共同形成观察范围。两者只过滤任务，不改变项目是否参与自动化，也不重排自动队列。
- 待处理列表显示由 Runtime 计算的跨项目队列序号；列表自身的搜索或排序只改变显示，不改变真实领取顺序。
- 待评审任务只有在用户具备状态更新权限并明确选择“确认可处理”后才变为待处理。
- 进行中任务有且仅有一个本地关联 Runtime 时，主动作是“打开运行”；没有关联 Runtime、存在多个关联 Runtime或项目工作区失效时进入恢复中心。
- 已完成任务的主动作是“审查结果”；用户可以提出独立验收问题。只有不存在 queued、running、awaiting_human 或 blocked 问题且证据完整时，才允许标记已验收。
- 已取消任务是只读终态。已验收任务表示验收通过，不重新打开原待办执行，也不允许新增验收问题。
- 已阻塞任务有可恢复的原 Runtime 时可以恢复原运行；否则只能在依赖解除后返回待处理队列。
- 任意状态更新都以服务器返回为准。版本冲突、权限变化或任务已被其他客户端修改时，不覆盖服务器状态。
- 创建与编辑表单的执行人只展示所选产品的成员名称，不附加产品名前缀；“未分配”保持可选。
- 优先级使用“最高、高、中、低、无优先级”选项，分别承载 Workshop 的 `0、1、2、3、未设置` 语义，不向用户暴露自由数字输入。
- 标签候选来自所选产品的项目标签实体，待办只提交逗号分隔的标签 ID。用户可以在表单内创建并自动选中新标签，也可以编辑名称和颜色或确认删除；标签变更成功后保留仍有效的待办草稿与选择。

### 信息架构

#### 应用壳

- 左侧保留 Today、Work、Automation、Feedback 与 Organization 产品级入口，Work 高亮；不显示项目列表或 `TASK STATUS` 分组。
- 顶部产品集控件显示当前项目范围；Work 内容区七状态筛选高亮当前状态，数量限定在该项目范围。
- 顶部命令栏展示产品集范围、管理项目集、服务器快照时间、搜索和刷新。

#### 任务内容区

1. 标题展示当前状态、项目范围、结果数量和一句状态解释。
2. 筛选条展示搜索、排序与“仅显示可执行”等辅助过滤。
3. 任务表格展示任务、项目、优先级、更新时间、执行/结果状态。
4. 右侧 Inspector 与列表同屏且始终可见，展示服务器事实、项目与本地工作区、关联 Runtime、证据摘要、状态历史和可用动作；completed 状态额外展示全部验收问题项、独立状态、Case/Run、最近进展和问题 Composer；accepted 状态只显示验收通过，不展示 Composer。
5. 页面标题区提供“创建待办”；可管理的任务行提供“编辑”。创建与编辑使用同一 Sheet 字段语义，标签选择和标签生命周期管理位于表单内。

### 状态流

`Work → 选择七种任务状态之一 → 同屏任务列表与 Inspector → 选择任务 → 更新 Inspector`

`待评审 → 确认可处理 → 待处理 → 从当前列表移出 → Command Center 队列更新`

`进行中 → 打开关联 Runtime → Command Center 当前运行或 Intervention Workbench`

`进行中但无有效 Runtime → Automation Recovery Center → 重试启动 / 标记阻塞`

`已完成 → 审查结果 → 标记已验收 → 已验收`

`已完成 → 提出验收问题 → 独立问题 queued → 查看进展或同一对话 → resolved`

`已完成且没有未解决验收问题 → 标记已验收 → 已验收只读结果`

`已阻塞 → 恢复原运行 → 进行中` 或 `已阻塞 → 返回队列 → 待处理`

`提交状态更新 → 版本冲突 → 刷新服务器事实 → 保留新状态并重新选择动作`

`创建待办 → 选择产品 → 加载该产品成员/父待办/标签 → 选择语义优先级与标签 → 服务器确认 → 刷新 Work`

`编辑待办 → 使用所属产品候选 → 保存字段 → 服务器确认 → 刷新列表与 Inspector`

`表单内创建/编辑/删除标签 → 服务器确认 → 刷新当前产品标签 → 保留仍有效的表单草稿与已选标签`

### 响应与恢复

- 状态更新期间锁定当前任务动作，但允许浏览其他任务。
- 成功后显示服务器确认结果，并同步当前筛选数量、项目计数和 Command Center 队列。
- 任务移出当前状态时，在原位置显示短暂结果提示，随后选中相邻任务；列表为空则进入当前范围空状态。
- 拉取失败时保留最近成功结果和快照时间，不把旧数据计入自动领取判断。
- 版本冲突时展示“服务器状态已变化”，刷新 Inspector，不自动重试原操作。
- 进行中任务失去 Runtime、工作区、项目权限或服务器归属时，Task Browser 只展示异常并进入 Recovery Center，不直接修复状态。
- 产品切换会立即清除上一个产品的执行人、父待办和标签选择，防止提交跨产品 ID。
- 标签创建、编辑或删除失败时保留待办表单和当前选择，并显示服务端错误；删除必须先确认。

### 输入输出边界

- 输入包括项目范围、任务状态、服务器任务快照、产品成员与标签、本地项目绑定、Runtime 关联、用户权限与搜索条件。
- 输出包括筛选后的任务列表、产品限定的待办创建/编辑请求、项目标签管理请求、状态更新请求、独立验收问题创建请求与进展、Runtime/Workbench/Recovery Center 导航和审查结果；不向 Feedback 页面输出验收问题。
- 任务服务器拥有项目归属、任务内容和七种任务状态；Task Browser 不直接修改本地 Runtime 状态。
- Renderer 不自行推断状态更新成功；只有服务器响应后才更新任务事实。
- 搜索、显示排序和项目/状态筛选不影响自动队列；自动队列顺序只由 Command Center 的确定性策略生成。

### 线框投影要求

- `default.html` 投影待处理列表、待评审确认、进行中任务、已完成任务的验收问题详情、已验收只读结果、已阻塞恢复、取消任务确认、空状态和同步/版本冲突；`task-form.html` 投影创建/编辑 Sheet、产品联动字段和标签管理。
- 状态操作确认必须在设备框内投影为 Sheet、Alert 或 ConfirmationDialog。
- 所有状态保持同一顶部产品集范围、Work 主导航高亮和列表/Inspector 双栏，不产生额外的返回 Work 路径。

## 导航流程

### 进入方式

- 主导航进入 Work 时直接显示默认状态的 Task Browser 列表与右侧 Inspector。
- Work 面板内的七种任务状态直接替换同屏列表与 Inspector。
- Work 指标卡可预设顶部产品范围与状态，并落在同一 Work 面板。
- 桌面通知可以深链到指定任务；页面仍先恢复项目和服务器任务事实。

### 页面内导航

- 切换项目保留当前任务状态；切换状态保留当前项目范围。
- 选择任务只更新 Inspector，不改变 URL 中的项目与状态筛选。
- 打开运行返回 Command Center 的当前运行；人工处理进入 Intervention Workbench。
- 异常进行中任务进入 Automation Recovery Center。

### 离开方式

- 切换到其他 ADVANCE 页面时保留顶部产品集范围和 Work 当前状态，不保留临时搜索文本。
- 状态更新成功后仍停留在 Work，并选择当前结果中的相邻任务。
- 设置或工作区绑定完成后返回原任务 Inspector，并重新验证执行资格。

## 交互行为

### 项目与状态导航

- 项目和状态是两个正交筛选轴，当前组合始终显示在标题和面包屑中。
- “项目集全部”聚合当前 Workset 内当前用户可访问项目的任务，不产生新的任务副本。
- 状态数量来自同一服务器快照；部分项目同步失败时显示不完整标记。

### 列表与 Inspector

- 待处理列表按真实自动队列序号展示；其他状态默认按更新时间倒序展示。
- 搜索只匹配当前项目与状态范围。
- 首次进入或当前选中任务离开筛选结果时自动选择首条结果；列表为空时 Inspector 显示选择空态。
- Inspector 始终展示任务所属项目，避免跨项目聚合时误操作。
- Work 内容区占满应用壳剩余高度，页面框架不随任务内容整体滚动；左侧任务列表和右侧 Inspector 分别在各自面板内纵向滚动，滚动任一侧不移动标题、状态筛选或另一侧内容。
- 无权限的状态操作隐藏或禁用，并解释权限来源。

### 状态操作

- “确认可处理”执行 `pending_review → pending`。
- “标记已验收”执行 `completed → accepted`。
- “提出验收问题”只在 completed 状态创建独立问题项并追加同一待办会话消息，不改变 completed 状态，也不把任务返回待处理队列。
- “标记已验收”只在没有未解决验收问题时可用；accepted 状态不提供验收问题 Composer。
- “返回队列”执行 `blocked → pending`；“恢复原运行”执行 `blocked → in_progress` 并恢复原 Runtime。
- “取消任务”只对非终态且没有活动 Runtime 的任务开放；活动 Runtime 必须先进入 Recovery Center 安全停止。
- Task Browser 不提供待处理任务的“立即执行”；领取由自动队列负责。

### 创建与编辑待办

- 创建表单始终显示产品字段；当前顶部范围是 Workset 内有效单产品时默认使用该产品，否则使用 Workset 首个可创建产品。
- 切换产品后，执行人、父待办和标签候选同步切换到新产品并清除旧选择。成员选项只显示名称，不显示产品名前缀或内部 ID。
- 编辑表单固定任务所属产品，执行人、父待办和标签只从该产品取值。
- 优先级使用固定语义选项，不提供自由数字输入。
- 标签区域显示当前产品标签名称和颜色，支持多选、创建并选中、就地编辑以及确认删除；保存待办时提交标签 ID 字符串。

## 弹窗/对话框

| 名称 | 触发 | data-kit | 内容 |
|---|---|---|---|
| 确认可处理 | 待评审任务进入待处理 | Sheet | 项目、任务、执行资格和确认动作 |
| 验收任务 | 已完成任务标记已验收 | ConfirmationDialog | 结果证据、终态影响和确认动作 |
| 恢复阻塞任务 | 已阻塞任务恢复 | ConfirmationDialog | 恢复原运行或返回队列的差异 |
| 取消任务 | 非终态任务取消 | ConfirmationDialog | 当前状态、Runtime 影响和取消动作 |
| 版本冲突 | 状态更新返回版本变化 | Alert | 服务器新状态和刷新动作 |
| 创建/编辑待办 | 标题区创建或任务行编辑 | Sheet | 产品限定字段、语义优先级、标签选择与标签管理 |
| 删除标签 | 表单内删除项目标签 | ConfirmationDialog | 标签名称、删除影响和确认动作 |

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
|---|---|---|
| 任务列表拉取失败 | 保留旧列表并标记过期 | 重试当前项目与状态 |
| 状态更新失败 | Inspector 就地错误 | 重试或保持服务器状态 |
| 版本冲突 | Alert 与刷新后的 Inspector | 基于新状态重新操作 |
| 权限不足 | 禁用动作与权限说明 | 刷新身份或返回只读浏览 |
| 进行中但无 Runtime | Inspector 异常卡 | 进入 Recovery Center |
| 项目工作区失效 | 项目与执行资格提示 | 重新绑定后再验证 |
| 产品候选加载失败 | 表单保留已输入内容并标记对应字段不可用 | 刷新当前产品数据或取消 |
| 标签管理失败 | 标签区域就地错误，待办草稿和选择保持 | 重试标签动作或继续使用现有标签 |

## 加载策略

| 场景 | 策略 |
|---|---|
| 首次进入 | 保留应用壳，加载当前项目与状态列表 |
| 切换项目或状态 | 保留标题与筛选，替换表格骨架 |
| 搜索 | 本地过滤已加载页，服务端分页继续携带筛选条件 |
| 状态更新 | 锁定当前任务动作，其他列表浏览不阻塞 |
| 分页 | 表格底部加载下一页并保留当前选中任务 |
| 打开创建/编辑表单 | 使用当前服务器快照立即渲染；产品切换只替换产品限定字段 |
| 标签管理成功 | 刷新当前产品标签并保留仍有效的待办草稿和已选标签 |
