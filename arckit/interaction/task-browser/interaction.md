# Task Browser - 交互规范

## 交互策略

### 核心任务

用户在 Work 面板内使用七种任务状态查询 Work Sync 的本地 Task Projection，在顶部产品集观察范围内创建或编辑明确产品归属的待办。新建和编辑 Sheet 提供完整七状态选择，其中编辑 Sheet 是异常或纠偏场景的自由修改兜底；右侧 Inspector 按当前状态提供明确、有限的下一步动作，引导正常状态流转。Task Browser 是 Work 的同屏内容区，不是独立主导航页面；它负责团队待办维护、服务器同步、观察和人工状态处置。Automation 只消费 Work Sync 发布的状态，不决定这些状态动作是否可用。

### 用户场景

1. 用户在顶部选择“项目集全部”，再选择 Work 的“待处理”筛选，在同屏列表与 Inspector 中查看哪些任务已经获得自动执行资格，以及它们在跨项目队列中的顺序。
2. 用户从单个项目的“待评审”进入，阅读任务详情并明确确认其可以进入待处理队列。
3. 用户从“进行中”进入，打开关联 Runtime；任务没有本地 Runtime 或状态异常时进入 Automation Recovery Center。
4. 用户从“已完成”进入，在右侧 Inspector 审查结果、全部验收问题及进展，提出新的验收问题；没有未解决问题且证据充分时可以将任务标记为已验收。已完成列表按新完成在上、历史完成在下排列；验收首项后选择下一条较旧待办，验收中间或末尾项后选择与原位置相邻的较新待办。
5. 用户从“已验收”进入，Inspector 显示验收通过和“当前没有待处理的验收问题”，不提供问题 Composer；从“已取消”进入时 Inspector 不提供下一状态动作，从“已阻塞”进入时可以返回待处理或取消。需要越过正常流转纠偏时，用户进入编辑 Sheet 选择任一七状态；Automation 只在确认结果发布后对账队列或恢复。
6. 用户操作任务时发现服务器版本已变化。页面不覆盖新状态，而是刷新该任务并解释冲突。
7. 用户创建或编辑待办时先确认产品并可选择完整七状态。编辑时可切换到当前产品集中另一个可写产品；执行人、父待办和标签只显示目标产品的数据；优先级使用有意义的固定档位，标签可在表单内选择、创建、编辑或删除。
8. 用户选择带图片评论的待办时，图片随评论时间线自动加载；用户点击图片后在独立窗口查看，并通过工具栏、鼠标或键盘完成缩放、适配、旋转、平移、重置和另存为。

### 主路径

1. Work 读取顶部产品集观察范围和面板内任务状态；直接进入 Work 时激活当前登录代际的本地 Task Projection，默认使用“项目集全部 / 待处理”。切换状态、搜索或筛选只切换本地查询并立即显示结果或本地初始化态，不触发后台远端刷新。
2. Work 保留同一应用壳，左侧只高亮 Work；当前项目范围显示在全局产品集控件。页面不重复展示占据纵向空间的大标题和说明区，Work 身份、七状态、搜索、筛选摘要和创建动作集中在一条固定高度的页面控制轨。
3. 常规桌面宽度下，控制轨完整展示七状态分段、搜索框和统一“筛选”触发器；创建人、执行人、标签、优先级和创建日期在同一个弹出面板内分组选择，触发器显示已启用维度数量，清除动作位于面板内。控制轨下方立即同屏渲染左侧父子任务树与右侧 Inspector，并让双栏取得应用壳除全局栏和控制轨之外的全部剩余高度。Inspector 首次使用 440px 宽度；列表与 Inspector 之间保留可聚焦的垂直分隔条，用户可在 360–640px 持久范围内拖拽调整。服务端返回的命中数量与为解释层级补全的父链/子树分别表达。
4. 首次进入、切换筛选或切换产品范围时自动选中结果中的首条命中任务；用户选择父任务或子任务时只更新右侧 Inspector。列表行使用从正文生成的单行展示标题，连续空白折叠为一个空格，超过 64 个 Unicode grapheme clusters 时以 `…` 收束。Inspector 标题区使用任务 ID、产品和状态识别当前对象，正文区域只展示一次保留换行的完整 Markdown 内容，并继续展示父任务、创建人、执行人、时间字段、评论附件、本地工作区、自动执行资格、关联 Runtime 和可用动作。评论时间线解析后自动加载图片并逐张显示状态；点击已加载图片打开独立图片浏览窗口，不替换 Work 页面。
5. 用户触发“创建待办”时，表单以当前有效单产品范围或 Workset 首个产品为默认值，并以待评审作为可修改的状态默认值。创建与编辑 Sheet 都显示产品选择器；编辑初值为任务当前产品。切换产品立即清空并替换执行人、父待办和标签候选，保留正文、状态和优先级草稿。
6. 用户保存同产品编辑时，页面把明确状态和字段提交给 Work Sync。用户改变产品时，Sheet 先展示新 Task 身份及不会复制的评论、附件、Run/thread 和详情引用；确认后 Work Sync 先创建目标 Task，创建成功才删除源 Task，并分别呈现两个步骤。Automation 状态、活动 Runtime 或验收问题不参与客户端许可判断。
7. Work Sync 发布服务器确认后的本地任务状态，任务才从当前筛选结果移出或更新；状态计数、Command Center 队列和 Inspector 共同响应同一本地 revision。
8. 用户切换到 Automation 时保留顶部产品范围；从 Runtime 入口进入时可直接返回对应运行。

### 决策点

- 顶部产品集范围和 Work 面板状态共同形成观察范围。两者只过滤任务，不改变项目是否参与自动化，也不重排自动队列。
- 待处理列表显示由 Runtime 计算的跨项目队列序号；列表自身的搜索或排序只改变显示，不改变真实领取顺序。
- “确认可处理”、标记阻塞、返回待处理、取消和验收是 Inspector 的正常状态流转入口；Inspector 不同时提供任意七状态 Picker。需要越过正常路径纠偏时，用户进入编辑 Sheet 使用完整七状态选择。
- 进行中任务有且仅有一个本地关联 Runtime 时，主动作是“打开运行”；没有关联 Runtime、存在多个关联 Runtime或项目工作区失效时进入恢复中心。
- 已完成任务的主动作是“审查结果”；用户可以提出独立验收问题。“标记已验收”只在没有未解决验收问题时出现。若需要改为其他服务器状态，用户从编辑 Sheet 使用完整七状态兜底。
- 已取消和已验收在 Inspector 中不提供通用下一状态流转；它们仍可通过编辑 Sheet 按 Workshop 权限、冲突检查和服务器确认纠偏。已验收任务不允许新增验收问题，除非先由服务器确认改为允许提出问题的状态。
- 已阻塞任务有可恢复的原 Runtime 时可以恢复原运行；否则只能在依赖解除后返回待处理队列。
- 任意状态更新都以 Work Sync 发布的服务器确认结果为准。版本冲突、权限变化或任务已被其他客户端修改时，Work 保持原本地状态并展示恢复结果，不执行乐观覆盖。
- 活动 Runtime 不阻止 Work 提交状态。确认后的新状态与活动 execution 冲突时，Automation 安全停止对应 Runtime、生成外部变化恢复项并保持人工 Gate 关闭；其他 workspace lane 不受影响。
- 创建与编辑表单的执行人只展示所选产品的成员名称，不附加产品名前缀；“未分配”保持可选。
- 优先级使用“最高、高、中、低、无优先级”选项，分别承载 Workshop 的 `0、1、2、3、未设置` 语义，不向用户暴露自由数字输入。
- 标签候选来自所选产品的项目标签实体，待办只提交逗号分隔的标签 ID。用户可以在表单内创建并自动选中新标签，也可以编辑名称和颜色或确认删除；标签变更成功后保留仍有效的待办草稿与选择。
- 多维筛选使用 Work Sync 的完整本地 Task Projection，不用 Renderer 当前可见窗口计算完整命中数，也不因筛选变化请求 Workshop。创建人、执行人、标签、优先级和日期范围使用弹出菜单选择；触发器显示摘要或已选数量，菜单关闭不清除选择。日期范围最多 100 天；页面明确默认范围、关系补全项和清除动作。
- 七状态、搜索、统一多维筛选触发器和“创建待办”共同占用一条页面控制轨。控制轨不因结果数量、项目名、筛选摘要、同步提示或状态计数变化而换行或增高；命中数、关系补全数和同步反馈归入列表标题栏，不挤占控制轨。
- 受支持的窄窗口下，控制轨仍保持单行：七状态分段收敛为显示当前状态和数量的状态菜单，筛选触发器保留已启用维度数量，低频页面动作进入“更多操作”；搜索、当前状态、筛选入口和“创建待办”保持可达。窗口恢复宽度后重新显示七状态分段，不改变筛选、选择或滚动位置。
- 任务树筛选命中项时保留其父链和子树。调整父任务时排除当前任务和全部后代，服务端循环检测是最终约束。
- TaskAttachment 在详情中按评论/附件时间线呈现；无法解析的历史正文按安全纯文本显示。Task history 服务端契约未成立时不显示伪历史。
- 展示标题不是独立输入或可编辑字段。创建和编辑表单只维护完整正文；列表、父任务候选、删除确认和 Runtime 入口统一从正文取得同一展示标题。Inspector 不把展示标题作为正文上方的第二份内容。
- 评论中的图片默认自动加载，单张失败只影响该图片并提供重试。图片浏览窗口不接收任意 URL 或本地路径，主进程按当前任务、附件记录和 object key 重新验证后才交付图片。
- 图片浏览窗口的常用操作集合固定为放大、缩小、适合窗口、实际大小、左旋、右旋、重置、缩放后拖拽平移和另存为；窗口关闭后返回原 Work 上下文，内联预览保持已加载。

### 信息架构

#### 应用壳

- 左侧保留 Today、Work、Automation、Feedback 与 Organization 产品级入口，Work 高亮；不显示项目列表或 `TASK STATUS` 分组。
- 顶部产品集控件显示当前项目范围；Work 内容区七状态筛选高亮当前状态，数量限定在该项目范围。
- 全局顶部命令栏只承载产品集范围、管理项目集和服务器快照语义；Work 页面控制轨承载任务状态、搜索、多维筛选入口和“创建待办”。

#### 任务内容区

1. 页面控制轨固定为一个视觉行，左侧显示 Work 身份与七状态分段，中部显示搜索和统一多维筛选触发器，右侧显示“创建待办”；不再使用独立大标题、说明区或第二条筛选卡片。
2. 多维筛选弹出面板包含创建人、执行人、标签、优先级、日期范围、清除和关闭动作。面板覆盖在工作台之上，不参与页面高度计算，也不裁切在列表或 Inspector 的滚动容器中。
3. 任务树每项只占一个视觉行，以同一行内缩进表达父子层级，并展示单行有界任务标题、项目、优先级、执行人和状态；关系补全项使用同一行的弱化标记，不增加说明副行。超长标题以单字符 `…` 结束，完整正文不在列表行展开。
4. 任务行不展示编辑、评论附件、删除或状态操作按钮；点击整行只更新选择。
5. 右侧 Inspector 与任务树同屏且始终可见，标题区只显示任务 ID、项目和状态，并把当前状态的有限下一步动作放在身份区；它不提供完整七状态 Picker 或通用“更新状态”按钮。Inspector 正文维持一个内部滚动区，依次使用清晰标题和独立浅层表面组织“内容”“属性”“协作”“验收”：内容只展示一次保留换行的完整 Markdown；属性以两列紧凑字段排列，标签、本地工作区和自动执行资格等长值跨两列，窄于 400px 的有效宽度降为单列；协作承载编辑/管理动作、评论与附件；验收只在 completed/accepted 语义适用时出现，completed 展示问题进展与 Composer，accepted 展示只读验收结果而不展示 Composer。
6. 页面控制轨提供“创建待办”；创建 Sheet 与编辑 Sheet 提供完整七状态选择，编辑 Sheet 承担异常纠偏兜底。编辑、评论附件、删除和上下文 Automation 查看动作继续位于 Inspector。标签选择和标签生命周期管理位于表单内。
7. 双栏工作台使用 `minmax(0, 1fr)` 语义取得控制轨下方全部剩余高度。列表标题栏和 Inspector 标题栏保持可见，任务行区域与 Inspector 正文区域分别滚动；页面外层不随长列表、长正文、空态或错误态滚动。Inspector 的已保存宽度是全局 Work 界面偏好，不随任务、项目或 Workset 切换；应用重启后在首次 Work 布局前恢复。

### 状态流

`Work → 选择七种任务状态之一 → 同屏任务列表与 Inspector → 选择任务 → 更新 Inspector`

`新建 / 编辑 → 选择任一七状态 → Work Sync mutation → 服务器确认 → 本地投影发布 → Automation 消费并对账`

`Inspector → 按当前状态选择有限下一步动作 → Work Sync task.update → 服务器确认 → 本地投影发布 → Automation 消费并对账`

`待评审 → 确认可处理 → 待处理 → 从当前列表移出 → Command Center 队列更新`

`进行中 → 打开关联 Runtime → Command Center 当前运行或 Intervention Workbench`

`进行中但无有效 Runtime → Automation Recovery Center → 重试启动 / 标记阻塞`

`已完成 → 审查结果 → 标记已验收 → 已验收`

`已完成 → 提出验收问题 → 独立问题 queued → 查看进展或同一对话 → resolved`

`已完成且没有未解决验收问题 → 验收快捷动作 → 已验收结果`

`已阻塞 → 恢复原运行 → 进行中` 或 `已阻塞 → 返回队列 → 待处理`

`提交状态更新 → 版本冲突 → 刷新服务器事实 → 保持服务器新状态并重新选择动作`

`创建待办 → 选择产品 → 加载该产品成员/父待办/标签 → 选择语义优先级与标签 → 服务器确认 → 刷新 Work`

`编辑待办 → 切换目标产品 → 确认复制范围 → 创建目标 Task → 删除源 Task → 对账两个产品 → 打开新 Task`

`表单内创建/编辑/删除标签 → 服务器确认 → 刷新当前产品标签 → 保留仍有效的表单草稿与已选标签`

`组合任务筛选 → 本地 Task Projection 返回命中数和任务树 → 展开父子关系 → 选择任务更新 Inspector`

`当前任务 → 创建子待办 / 调整父待办 → 排除循环候选 → 服务器确认 → 刷新任务树`

`任务详情 → 读取评论附件 → 新增或维护有权限记录 → 服务器确认 → 保持当前任务`

`任务详情 → 评论图片自动加载 → 点击已加载图片 → 独立图片浏览窗口 → 缩放 / 适配 / 实际大小 / 旋转 / 平移 / 重置 / 另存为 → 关闭窗口返回原任务`

### 响应与恢复

- 状态更新期间锁定当前任务动作，但允许浏览其他任务；若用户在请求完成前选择其他任务，服务器成功结果不得覆盖这次较新的选择意图。
- 成功后显示服务器确认结果，并同步当前筛选数量、项目计数和 Command Center 队列。
- 活动 execution 遇到用户确认后的状态变化时，Work 保持成功结果；Automation 单独显示安全停止和外部变化恢复，不把状态更新回滚成旧状态。
- 任务移出当前状态时，在原位置显示短暂结果提示，随后选中相邻任务；列表为空则进入当前范围空状态。已完成列表的验收选择以状态更新前的当前可见顺序为依据：选择首项时转到下一条较旧待办，选择其他位置时转到上一条较新待办；父子树补全项不参与相邻目标计算。
- 拉取失败时保留最近成功结果和快照时间，不把旧数据计入自动领取判断。
- 从其他页面进入 Work 不等待 Automation 或 Workshop 请求完成才切换页面；页面立即读取本地 Task Projection，Work Sync 后续同步失败时继续保留最近成功列表与 Inspector，并在独立同步状态中反馈。
- 加载、空结果、错误和刷新状态替换列表或 Inspector 的内部正文，不改变控制轨高度、双栏高度和分栏比例；筛选弹出面板关闭后焦点返回触发器。
- 版本冲突时展示“服务器状态已变化”，刷新 Inspector，不自动重试原操作。
- 进行中任务失去 Runtime、工作区、项目权限或服务器归属时，Task Browser 只展示异常并进入 Recovery Center，不直接修复状态。
- 产品切换会立即清除上一个产品的执行人、父待办和标签选择，防止提交跨产品 ID；切回原产品也不自动恢复已清除选择。
- 产品归属变更提交期间锁定当前编辑动作。目标创建失败时源 Task 不变并保留草稿；目标创建成功后页面显示新 Task id，再进入源删除步骤。
- 源删除失败时页面同时展示新旧 Task，说明操作尚未完整结束，并提供“重试删除旧待办”和“保留两份”动作；不得把双 Task 状态隐藏为成功或自动删除新 Task。
- 活动 execution 不隐藏或禁用产品选择器。源 Task 删除确认后，Automation 在旧 lane 安全停止对应 execution 并展示外部变化恢复；新 Task 不继承旧 execution、thread 或 Gate，其他 lane 不受影响。
- 标签创建、编辑或删除失败时保留待办表单和当前选择，并显示服务端错误；删除必须先确认。
- 单张评论图片加载失败时保持评论正文和其他资源，失败占位提供就地重试；独立窗口打开或保存失败时保持内联预览和浏览窗口，不改变任务选择。
- 标题投影失败时使用任务 ID 保持对象可识别，并记录数据异常；页面不回退把未折叠的完整正文塞入单行标题区域，也不修改远端正文。

### 输入输出边界

- 输入包括项目范围、任务状态、服务器任务快照、产品成员与标签、本地项目绑定、Runtime 关联、用户权限与搜索条件。
- 输出包括筛选后的任务树、明确目标产品的待办创建/编辑、跨产品复制与源删除请求及其分步结果、父子关系请求、评论附件及受控图片浏览/另存为请求、项目标签管理请求、状态更新请求、独立验收问题创建请求与进展、Runtime/Workbench/Recovery Center 导航和审查结果；不向 Feedback 页面输出验收问题。
- 任务服务器拥有项目归属、任务内容和七种任务状态；Task Browser 不直接修改本地 Runtime 状态。
- Renderer 不自行推断状态更新成功；只有服务器响应后才更新任务事实。
- 搜索、显示排序和项目/状态筛选不影响自动队列；自动队列顺序只由 Command Center 的确定性策略生成。

### 线框投影要求

- `daily-work.html` 投影单行页面控制轨、统一多维筛选弹出入口、取得剩余高度的任务树/Inspector、440px 默认与可访问分隔条、紧凑属性和内容/协作/验收分区、父子关系、评论图片默认加载和独立图片浏览窗口；`default.html` 投影待处理列表、待评审确认、进行中任务、已完成任务的验收问题详情、已验收只读结果、已阻塞恢复、取消任务确认、空状态和同步/版本冲突；`task-form.html` 投影创建/编辑 Sheet、产品联动字段和标签管理；`readiness-guidance.html` 投影待评审、执行人和项目连接缺口的就地解释与动作。
- 状态操作确认必须在设备框内投影为 Sheet、Alert 或 ConfirmationDialog。
- 所有状态保持同一顶部产品集范围、Work 主导航高亮和列表/Inspector 双栏，不产生额外的返回 Work 路径。

## 导航流程

### 进入方式

- 主导航进入 Work 时直接显示默认状态的 Task Browser 列表与右侧 Inspector。
- Work 面板内的七种任务状态直接替换同屏列表与 Inspector。
- Work 指标卡可预设顶部产品范围与状态，并落在同一 Work 面板。
- 桌面通知可以深链到指定任务；页面仍先恢复项目和服务器任务事实。

### 页面内导航

- 切换项目保留当前任务状态；切换状态保留当前项目范围。
- 选择任务只更新 Inspector，不改变 URL 中的项目与状态筛选。
- 打开运行返回 Command Center 的当前运行；人工处理进入 Intervention Workbench。
- 异常进行中任务进入 Automation Recovery Center。

### 离开方式

- 切换到其他 ADVANCE 页面时保留顶部产品集范围和 Work 当前状态，不保留临时搜索文本。
- 状态更新成功后仍停留在 Work。验收请求等待期间没有产生更晚的显式用户选择意图时，服务器确认后已完成列表执行相邻自动选择：首项后选择下一条较旧待办，其他位置后选择上一条较新待办；等待期间用户显式选择其他任务时保留新选择，Work Sync 刷新造成的系统回退不视为显式用户意图，目标在刷新后不可见时使用当前结果的安全回退，列表为空时清空 Inspector。
- 设置或工作区绑定完成后返回原任务 Inspector，并重新验证执行资格。

## 交互行为

### 项目与状态导航

- 项目和状态是两个正交筛选轴，当前组合始终显示在标题和面包屑中。
- “项目集全部”聚合当前 Workset 内当前用户可访问项目的任务，不产生新的任务副本。
- 七个状态数量来自同一次最新本地 Task Projection 查询，并使用当前产品范围、搜索、成员、标签、优先级和日期条件；状态本身只决定列表内容，不改变其他入口的计数新鲜度。
- Work Sync 本地投影刷新会更新全部状态入口数量；状态切换保留这组最新计数，不从页面级 Platform snapshot 或已离开的状态查询恢复旧值。部分项目尚未完成 Work Sync 对账时显示不完整或过期标记。

### 列表与 Inspector

- 待处理列表按真实自动队列序号展示；其他状态默认按更新时间倒序展示。
- 搜索只匹配当前项目与状态范围。
- 首次进入或当前选中任务离开筛选结果时自动选择首条结果；列表为空时 Inspector 显示选择空态。
- 组合筛选由本地 Task Projection 执行；父链和子树补全项不计入命中数量。日期范围明确显示且不超过 100 天。
- 父任务候选排除当前任务和全部后代；创建子任务、调整或清空父任务成功后保持筛选并刷新树。
- Inspector 始终展示任务所属项目，避免跨项目聚合时误操作。
- Work 页面控制轨始终保持一个视觉行和固定高度；常规宽度展示七状态分段、搜索、统一筛选入口和创建动作，窄窗口把七状态收敛为当前状态菜单并把低频动作放入溢出菜单。常规宽度的状态数量使用按钮右上角覆盖式角标，不参与图标与完整状态标题的网格宽度；项目名、命中数、补全树数量、状态计数和刷新提示不得改变控制轨宽高。命中与同步摘要在列表标题栏单行省略。
- Work 双栏内容区占满应用壳剩余高度，页面框架不随任务内容整体滚动；左侧任务列表正文和右侧 Inspector 正文分别在各自面板内纵向滚动，滚动任一侧不移动控制轨、面板标题或另一侧内容。
- Inspector 默认宽度为 440px，用户偏好只保存 360–640px 的整数。分隔条拥有 12px 可命中区域，指针拖拽只更新当前布局，结束拖拽后才持久化；双击恢复 440px。分隔条使用 `role="separator"`、`aria-orientation="vertical"` 和当前/最小/最大宽度值，可聚焦，并支持左右方向键每次调整 16px、`Shift` 加方向键每次调整 48px；键盘调整完成后持久化。
- 布局始终为左侧任务树保留至少 420px。窗口暂时不足以容纳保存宽度、12px 分隔条和列表最小宽度时，仅把本次布局的 Inspector 有效宽度收敛到可用值，不覆盖已保存偏好；窗口重新变宽后恢复保存值。缺失、非数值或越界偏好按 440px 回退或归一化到 360–640px。
- 拖拽、键盘调整、双击复位和窗口约束都不得重新创建 Inspector 内容；当前任务、两栏滚动位置、评论草稿、验收问题草稿及已加载附件状态保持不变。
- 无权限的状态操作隐藏或禁用，并解释权限来源。

### 状态操作

- “确认可处理”执行 `pending_review → pending`。
- “标记已验收”执行 `completed → accepted`。
- “标记已验收”在服务器确认前保留当前选择；确认成功且验收等待期间没有产生更晚的显式用户选择意图时，按更新前可见列表确定相邻目标，首项向下选择，其他位置向上选择。Work Sync 刷新造成的系统回退不阻止自动切换；等待期间产生的其他任务选择优先于自动切换。
- “提出验收问题”只在 completed 状态创建独立问题项并追加同一待办会话消息，不改变 completed 状态，也不把任务返回待处理队列。
- “标记已验收”只在没有未解决验收问题时可用；accepted 状态不提供验收问题 Composer。
- “标记阻塞”执行 `in_progress → blocked`；“返回待处理”执行 `blocked → pending`。
- “取消”只在待评审、待处理和已阻塞状态作为 Inspector 下一步动作出现。活动 Runtime 或 Automation 可见性不作为 Work mutation 的许可条件；服务器确认后的外部变化由 Automation 安全停止和恢复。
- 已取消不提供 Inspector 下一步动作；已验收只提供“查看验收结果”。任意状态纠偏从编辑 Sheet 提交完整七状态。
- Task Browser 不提供待处理任务的“立即执行”；领取由自动队列负责。

### 执行资格就地引导

- Task Inspector 根据所选任务与当前用户的实时事实解释 Automation 资格；只有“当前用户是执行人且状态为待处理”的普通待办才进入自动领取候选，待评审、未分配或分配给他人的任务均不进入。
- 所选任务为待评审、当前用户是执行人且项目连接完整时，首要动作使用“确认并交给 ArcOrbit”；该动作仍调用服务器的“确认为待处理”，成功后留在 Work 并让 Automation 从新投影自行领取。
- 所选任务尚未分配或分配给其他成员时，Inspector 明确显示当前执行人。具备编辑权限时提供“修改执行人”，否则显示所需项目角色和责任方，不暗示当前用户可以启动它。
- 任务状态已经是待处理但缺少本地目录或项目授权时，Inspector 显示同一资格原因及直接的“选择本地目录”或“允许此项目自动领取”；修复成功后留在当前 Inspector，并 fresh-read 项目和任务事实。
- 全局自动领取关闭不是任务自身错误。Inspector 只显示“任务已具备资格，等待全局自动领取”，并提供明确的“开始自动执行”；不得把任务状态回退或重复确认。
- 创建待办默认仍为待评审。只有用户从 Today 或 Work 明确选择“创建并交给 ArcOrbit”时，确认 Sheet 才同时明确当前用户、待处理状态和自动执行影响。

### 创建与编辑待办

- 创建表单始终显示产品字段；当前顶部范围是 Workset 内有效单产品时默认使用该产品，否则使用 Workset 首个可创建产品。
- 切换产品后，执行人、父待办和标签候选同步切换到新产品并清除旧选择。成员选项只显示名称，不显示产品名前缀或内部 ID。
- 编辑表单以任务当前产品为初值，并显示当前产品集内可写产品。切换目标产品后，执行人、父待办和标签只从目标产品取值，旧值全部清空。
- 新建与编辑表单始终显示完整七状态；编辑 Sheet 的状态字段不因 Automation 可见性、活动 execution 或验收问题隐藏，作为异常纠偏的兜底入口。
- 产品改变时，保存动作打开确认区，列出目标产品、新 Task 身份、复制的正文/状态/优先级和不复制的评论/附件/Run/thread/详情引用；用户确认后才开始目标创建。
- 目标创建成功后 Sheet 显示新 Task id 和“正在删除旧待办”；源删除失败时 Sheet 保持打开并提供重试删除或保留两份。完整成功后关闭 Sheet、打开新 Task，并保持当前产品集范围。
- 优先级使用固定语义选项，不提供自由数字输入。
- 标签区域显示当前产品标签名称和颜色，支持多选、创建并选中、就地编辑以及确认删除；保存待办时提交标签 ID 字符串。

### 详情与评论附件

- Inspector 身份区显示任务 ID、产品、状态和有限下一步动作；其下使用“内容”“属性”“协作”“验收”四个语义分区。各分区用标题、间距和浅层边界形成层级，不以一条顶边充当唯一分隔，也不把整个 Inspector 切成互相滚动的卡片。
- “内容”使用受限 Markdown 展示唯一完整正文；“属性”以紧凑两列显示创建人、执行人、父任务、优先级、创建时间、更新时间和完成时间，标签、本地工作区、Automation 资格与关联 Runtime 等长值跨列。有效宽度低于 400px 时属性降为单列，文本可换行但标签和值不截断为不可理解的缩写。
- “协作”包含编辑、创建子待办、复制引用等管理动作和 TaskAttachment 评论/附件时间线；“验收”与协作保持独立标题和表面，completed 显示验收问题数量、进展、Composer 及验收动作，accepted 只显示通过结果，其余状态不渲染空验收分区。
- 评论时间线复用 TaskAttachment；`text`、`file` 和 `url` 保留类型，文本正文兼容提及、链接、图片和文件引用格式。
- 时间线解析出图片后立即启动受限自动加载；每张图片独立显示加载骨架、缩略图或失败重试，不用一次点击换取首次显示，也不因某张失败隐藏评论正文。
- 点击缩略图打开独立图片浏览窗口。工具栏提供放大、缩小、适合窗口、实际大小、左旋、右旋、重置和另存为；鼠标滚轮或触控板缩放，图片超出视口时可以拖拽平移，常用工具同时提供可发现的键盘快捷键。
- 浏览窗口加载期间保留窗口框架与图片名称；打开失败显示可重试错误。关闭窗口只关闭浏览上下文，不改变 Work 的筛选、任务选择、滚动位置或内联图片状态。
- 项目成员可以读取和新增评论；只有附件创建者可以更新，删除还允许任务创建者、project admin 或 owner。Renderer 保守显示动作，Workshop 最终授权。
- 复制任务引用恢复同一产品和任务上下文；打开外部链接必须由用户明确触发。
- Task history 路由未成立时，不展示空时间线冒充已验证历史；详情只显示服务端时间字段和 ArcOrbit 自有 Run/Case 证据。

## 错误处理

| 错误类型 | 展示方式 | 恢复操作 |
|---|---|---|
| Work Sync 项目对账失败 | 保留旧列表并标记过期 | 请求 Work Sync 重新同步当前项目 |
| 状态更新失败 | Inspector 就地错误 | 重试动作或保持当前本地状态 |
| 版本冲突 | Alert 与刷新后的 Inspector | 基于新状态重新操作 |
| 权限不足 | 禁用动作与权限说明 | 刷新身份或返回只读浏览 |
| 进行中但无 Runtime | Inspector 异常卡 | 进入 Recovery Center |
| 项目工作区失效 | 项目与执行资格提示 | 重新绑定后再验证 |
| 产品候选加载失败 | 表单保留已输入内容并标记对应字段不可用 | 刷新当前产品数据或取消 |
| 目标 Task 创建失败 | 表单保留目标产品和全部草稿，源 Task 保持服务器事实 | 修正目标字段或重试创建 |
| 源 Task 删除失败 | Sheet 展示新旧 Task id 和未完整结束状态 | 重试删除旧待办或明确保留两份 |
| 标签管理失败 | 标签区域就地错误，待办草稿和选择保持 | 重试标签动作或继续使用现有标签 |
| 父子关系冲突 | 任务树和 Inspector 保持服务器现状 | 重新选择合法父任务或清空父任务 |
| 评论附件解析失败 | 以安全纯文本显示原内容 | 继续读取其他记录或刷新当前任务 |
| 评论图片加载失败 | 对应图片位置显示失败与脱敏原因 | 重试该图片，不重载整条时间线 |
| 图片浏览或另存为失败 | 独立窗口就地错误，保留当前变换和内联预览 | 重试打开或重新选择保存位置 |

## 加载策略

| 场景 | 策略 |
|---|---|
| 首次进入 | 保留应用壳，读取当前登录代际的本地 Task Projection；尚未初始化时显示 Work Sync 初始化或恢复态 |
| 切换项目或状态 | 保留标题与筛选，立即切换本地查询结果；不请求 Workshop，不显示由切换触发的同步提示 |
| 搜索 | 本地按完整任务内容查询并返回完整命中数，保留当前产品和其他筛选条件 |
| 组合筛选 | 本地返回命中数和层级结果，保留顶部产品范围 |
| 展开任务树 | 使用当前查询结果的父链和子树，不额外改变筛选 |
| 读取评论附件 | 选择任务后按 task id 加载；失败不隐藏任务详情 |
| 加载评论图片 | 评论时间线解析后按受控并发自动加载；任务或身份变化时丢弃旧响应，单张失败不阻塞其余图片 |
| 打开图片浏览 | 先显示独立窗口框架，再由主进程交付已验证图片；内联评论保持原位 |
| 状态更新 | 锁定当前任务动作，其他列表浏览不阻塞 |
| 分页 | 表格底部加载下一页并保留当前选中任务 |
| 打开创建/编辑表单 | 使用当前本地 Task Projection 立即渲染；产品切换只替换产品限定字段 |
| 标签管理成功 | 刷新当前产品标签并保留仍有效的待办草稿和已选标签 |
