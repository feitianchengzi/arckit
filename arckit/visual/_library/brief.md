# Runtime Desktop 视觉策略

## 来源依据

用户要求 Runtime Desktop 达到专业桌面平台的表达质量，并明确指定 `arckit/pending/prototypes/desktop-platform` 作为灵感来源。确认的 Automation Command Center、Task Browser、Intervention Workbench 和 Recovery Center 共同限定视觉系统必须支持高密度运行态势、项目与状态导航、按需人工处理和异常恢复。

## 品牌气质

界面呈现可靠、克制、精确的自动化控制台气质。视觉重点是可观察性、执行边界和状态可信度，不使用娱乐化插画、夸张渐变或大面积品牌色制造情绪。

## 信息层级

深色侧栏承载稳定控制结构，亮色工作区承载当前任务和证据。Command Bar 是全局操作层；页面标题与核心指标建立态势摘要；人工事项位于当前运行与队列之前；表格和 Inspector 承载细节。

活动对象通过左侧细描边、浅色底和语义标签共同突出。层级主要依靠背景面、分隔线、字体权重和空间组织，阴影不承担常规卡片分层。

Intervention Workbench 的消息层级以 Agent 正式正文为视觉主角，使用舒适行高和有限内容宽度；state-driven loop 状态使用低对比、横向紧凑的辅助提示；非空 reasoning 使用可折叠的次级文本面，完成后默认收起；schema-bound 输出使用可折叠的结构化结果面；工具活动使用最轻的一行列表样式。思考过程、结构化结果和工具活动不形成与 Agent 正文同等体量的气泡或卡片，空 reasoning 和原始 JSON 不在主消息面产生空占位或大块高对比内容。

独立 Login 与会话恢复状态属于亮色工作区，不延展深色侧栏或标题栏。认证画布使用中性浅灰承载低对比紫色光晕，白色账号面板保持输入焦点；深色墨色只用于文字和小面积标识，不形成全页背景。

## 色彩角色

中性墨色构成导航、文字、背景和边界。紫色是唯一操作强调色，用于当前导航、主按钮、焦点和活动 Runtime。绿色表达健康与完成，琥珀色表达待处理与人工注意，红色表达错误、取消和破坏操作，蓝色表达信息与同步，青色表达已验收或稳定外部确认。

七种任务状态必须同时使用明确中文文本、英文状态键的可访问说明和语义色。待评审使用中性灰，待处理使用琥珀，进行中使用紫色，已完成使用绿色，已验收使用青色，已取消使用红色，已阻塞使用深琥珀或红琥珀。

## 字体节奏

界面使用系统无衬线字体，并优先匹配 macOS 系统字体。标题采用紧凑字距与较高字重；运行数据、状态和辅助信息使用 10–13px 的紧凑阶梯；正文与人工对话使用 14px 以上和更舒适行高。标识符、时间和命令使用等宽字体。

## 空间密度

应用壳面向最小 1100×720 的桌面窗口。侧栏宽度稳定，Command Bar 紧凑，主页面以 8px 基础网格组织。导航行、工具按钮和表格行保持 30–40px 高度；页面区块使用 16–24px 间距；人工对话区域允许更宽松的 20–28px 节奏。Workbench 三栏与底部 Composer 保持稳定边界，中间消息列表占用剩余高度并独立滚动；工具活动行保持 28–32px 的紧凑高度。

## 组件性格

常规容器使用细边框、小圆角和纯色表面。主按钮使用实心紫色，次按钮使用白底细边框，文字按钮用于低风险导航。状态标签紧凑、可扫描，不使用大面积饱和底色。

任务表是主数据组件，行选择不改变队列语义。当前运行使用阶段条、状态点和有限事件摘要表达进度。人工事项使用浅琥珀背景和明确主动作；恢复事项使用浅红或浅琥珀背景，并展示事实差异和责任方。

WorkbenchTranscript 使用六类明确层级：LoopStatus 是中性或语义色的细边界提示，ReasoningDisclosure 是默认收起的次级过程文本，AgentMessage 是无多余装饰的主要阅读内容，StructuredResult 是展示 schema 与原始字段的低强调查看器，ToolActivity 是单行图标、动词、目标与结果，UserMessage 使用轻量区分的输入表面。Composer 以顶部分隔线固定在消息列底部，不通过重阴影覆盖内容。

## 状态表达

健康、同步、运行、等待人工、恢复和停止状态同时依赖图标或状态点、标签和说明文字。加载状态保留应用壳和布局，使用低对比骨架；空状态保持信息结构并提供首要动作；错误状态保留最近可信快照。

Workshop 账号状态沿用同一语义体系：未登录使用中性灰，验证码发送与 token 刷新使用信息蓝，已登录使用健康绿，会话失效使用错误红。账号标识保持可读但适度脱敏；access token、refresh token 和具体过期时间不形成视觉字段。认证错误在账号表单内就地出现，不占用 Runtime 人工事项的琥珀色层级。

hover 只轻微改变背景或边界，active 使用 0.98 缩放，focus 使用半透明紫色双像素轮廓。页面切换使用 160ms 淡入和 2px 位移，不使用长距离运动。

## 主题策略

当前确认主题是亮色工作区与深色控制侧栏的混合主题。系统跟随能力只影响原生窗口控件，不自动反转工作区信息层级。完整暗色工作区需要独立的人类确认后才能成为新主题。
