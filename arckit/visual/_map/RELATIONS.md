# Visual Relations

`_library/brief.md` 是 Runtime Desktop 视觉策略源。

`_library/design-tokens.yaml` 把策略投影为色彩、字体、间距、布局、圆角、阴影和动效变量。

`_library/component-catalog.yaml` 使用 tokens 定义 Login、Command Center、Task Browser、Intervention Workbench 和 Recovery Center 所需组件。

`_library/style-preview.html` 是 tokens 与组件状态的验收投影，不定义页面交互事实。

产品依据是 `arckit/spec/agentic-software-development/runtime-automation-workspace.md`；交互依据是 `arckit/interaction/login/interaction.md`、`arckit/interaction/automation-workspace/interaction.md` 和 `arckit/interaction/task-browser/interaction.md`。
