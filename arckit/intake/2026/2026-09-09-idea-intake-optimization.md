# Idea 接入体验优化

用户实测：选择材料目录后不知道如何继续。只读审计发现当前实现只有草稿表单和空对话，未建立 Agent 主导的主线；项目/组织/Git 上下文缺失，设计稿读取不足，建议使用 JSON 且不能直接修改，主操作和恢复阶段不明确。用户要求“完整优化”。

目标：选择材料后自动开始理解和准备方案；空白起点提供明确描述入口。Agent 理解材料、查询环境、准备方案、提出必要问题并在确认后执行；用户通过同屏结果修改、补充、确认和对话协作。当前步骤、阻塞原因与下一步持续明确。

保留：独立添加页、真实 Chat 消息与输入复用；仅现有 Workshop/GitHub；临时记录仅本机、正式 Idea 必须有 GitHub 和本地目录，位于 arckit/product，按产品集关联目录恢复。原 Lifecycle 保留；本事项不改变其他正在进行的 Release 工作。

优化：长期理念/原则/资产是可选完善；接入方案是可编辑业务信息而不是原始 JSON；界面编辑与 Agent 提案有明确版本/来源、保存/采纳和失效恢复。材料检测、环境查询、未准备好及失败均有可见结果；图片支持与不支持材料类型明确提示。重开不重复分析或创建，部分成功可继续。
